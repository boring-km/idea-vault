# Idea Vault

아이디어를 기록하고, 발전시키고, 관련 자료를 모아두는 저장소입니다.

## 구조

```
ideas/
  backlog/      # 아직 구체화하지 않은 아이디어
  in-progress/  # 현재 발전시키고 있는 아이디어
  done/         # 완료되었거나 실행에 옮긴 아이디어
resources/
  links/        # 참고 링크 모음
  files/        # 관련 파일 (이미지, PDF 등)
templates/      # 아이디어 작성 템플릿
```

## 사용법

1. `templates/idea-template.md`를 복사해서 `ideas/backlog/`에 새 파일을 만듭니다.
2. 아이디어를 구체화하면 `ideas/in-progress/`로 옮깁니다.
3. 실행에 옮기거나 완료되면 `ideas/done/`으로 옮깁니다.
4. 관련 자료는 `resources/`에 정리합니다.
