## 핵심 아이디어

한국 프리랜서를 위한 견적서/계약서 자동 생성, 인보이스 발행, 입금 추적, 세금 계산(3.3% 원천징수 등)을 한 곳에서 해결하는 올인원 비즈니스 관리 도구.

## 상세 설명

### 컨셉

프리랜서는 본업 외에도 견적, 계약, 청구, 세금 등 비즈니스 관리에 상당한 시간을 쓴다. 해외에는 FreshBooks, HoneyBook 등이 있지만 한국 세금 체계(3.3% 원천징수, 종합소득세, 부가세 등)를 지원하지 않는다. 이를 해결하기 위해:

1. **견적서 자동 생성**: 템플릿에 항목만 입력하면 전문적인 견적서 PDF 생성
2. **계약서 생성**: 용역 유형별 계약서 템플릿 + 전자서명
3. **인보이스 발행 + 입금 추적**: 발행 → 알림 → 입금 확인까지 자동 추적
4. **세금 계산기**: 3.3% 원천징수, 종합소득세 예상액, 부가세 계산

### 왜 지금인가

- 프리랜서/긱 이코노미 시장 지속 성장 (국내 230만+)
- 기존 해외 도구(FreshBooks, Wave 등)가 한국 세금 체계 미지원
- 프리랜서들이 엑셀/노션으로 수동 관리하는 비효율 상존

## 해결하려는 문제

| 문제 | 해결 방식 |
|------|-----------|
| 견적서를 매번 워드/한글로 직접 작성 | 템플릿 기반 자동 생성 (30초) |
| 계약서 작성이 어렵고 법적 보호 불안 | 용역 유형별 검증된 템플릿 제공 |
| 입금 여부를 수동으로 확인 | 인보이스 발행 → 입금 추적 자동화 |
| 3.3% 원천징수 계산이 헷갈림 | 자동 계산 + 연말 종합소득세 예상액 |
| 수입/지출 관리가 안 됨 | 간편 장부 + 경비 기록 |

## 수익 모델

```
[무료: 월 3건] → [스타터: 월 9,900원] → [프로: 월 19,900원]
                      │                      │
                      ├─ 견적서/인보이스 무제한  ├─ 전자서명 포함
                      ├─ 기본 계약서 템플릿      ├─ 프리미엄 계약서 템플릿
                      └─ 세금 계산기            ├─ 경비 관리 + 장부
                                               └─ 종합소득세 예상 리포트
```

## 기술 구현 방향

| 구성 요소 | 기술 | 설명 |
|-----------|------|------|
| PDF 생성 | Puppeteer / react-pdf | 견적서/인보이스/계약서 PDF 렌더링 |
| 전자서명 | 자체 구현 or DocuSign API | 계약서 전자서명 |
| 세금 계산 | 자체 로직 | 3.3% 원천징수, 종소세, 부가세 계산 |
| 알림 | 이메일 + 카카오 알림톡 | 인보이스 발송, 입금 리마인더 |
| 프론트엔드 | Next.js | 대시보드 + 문서 에디터 |
| 백엔드 | Node.js | API 서버 |
| DB | PostgreSQL | 사용자, 문서, 거래 데이터 |

## 경쟁 우위 / 차별화 전략

1. **한국 세금 체계 완벽 지원**: 3.3%, 종소세, 부가세 등 해외 도구가 못하는 영역
2. **한국어 문서 템플릿**: 견적서, 계약서, 세금계산서 한국 표준 양식
3. **간편함**: IT에 익숙하지 않은 프리랜서도 바로 사용 가능
4. **낮은 가격**: FreshBooks $15/월 대비 9,900원

## 리스크 및 고려사항

| 리스크 | 대응 방안 |
|--------|-----------|
| 세법 변경 시 계산 로직 업데이트 필요 | 세법 변경 모니터링 + 빠른 반영 |
| 계약서 법적 효력 관련 책임 | 법률 자문 후 면책 고지, 참고용 안내 |
| 사용자 확보 초기 어려움 | 프리랜서 커뮤니티 타겟 마케팅 |
| 유사 서비스 등장 가능 | 한국 특화 + 빠른 기능 확장으로 선점 |
