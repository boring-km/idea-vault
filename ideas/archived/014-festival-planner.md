> 공공데이터 활용으로 개발 난이도는 낮지만, 수익 모델이 약하고 계절성이 심함. 013번 팝업 헌터와 결합하여 이벤트 통합 플랫폼으로 발전 시 시너지 가능.

## 핵심 아이디어

"이번 주말에 어디 갈까?" → 날짜를 선택하면 그 기간에 전국에서 열리는 축제를 달력과 지도로 보여주고, 숙소/교통까지 연결하여 축제 중심 여행 플래너로 작동하는 서비스.

## 상세 설명

### 컨셉

여행을 계획할 때 보통 '장소'부터 정하지만, 막상 가면 아무 행사가 없어 심심할 수 있다. 반대로 '날짜'를 기준으로 접근하면:

1. **날짜별 달력**: 이번 주말(2/15~16)에 전국에서 열리는 축제 리스트
2. **시즌 테마**: 벚꽃/물놀이/단풍/불꽃/빛축제 등 계절별 필터
3. **여행지 매칭**: 강릉 선택 시 근처 축제 + 숙소 + 맛집 추천
4. **축제 상세**: 주요 프로그램, 주차 정보, 입장료, 혼잡도

### 왜 지금인가

- 국내 여행 수요 증가 (해외보다 간편한 국내 관광)
- 지자체마다 축제를 열지만, 정보가 각 홈페이지에 파편화
- 축제 정보는 있어도 '내가 갈 수 있는 날짜'에 뭐가 있는지 찾기 어려움
- 코로나 이후 야외 축제가 다시 활성화되며 수요 폭증

## 해결하려는 문제

| 문제 | 해결 방식 |
|------|-----------|
| 여행 날짜는 정했는데 뭐 하지? | 날짜 입력 시 전국 축제 일정 표시 |
| 축제 정보가 각 지자체 사이트에 흩어짐 | 통합 캘린더로 한눈에 보기 |
| 계절감 있는 축제만 보고 싶음 | 벚꽃/불꽃/빛축제 등 테마 필터 |
| 축제 가려면 숙소/교통도 알아봐야 함 | 축제 상세에서 주변 숙소 바로 예약 |

## 수익 모델

```
[무료: 축제 달력 + 지도] → [제휴 수수료]
                           │
                           ├─ 숙소 예약 제휴 (야놀자, 여기어때 등)
                           ├─ 렌터카 예약 제휴 (쏘카, 롯데렌터카 등)
                           ├─ 맛집 예약 제휴 (네이버 예약, 테이블링 등)
                           └─ 지역 관광 패키지 제휴

광고 수익:
- 지자체 관광공사 배너 광고
- 축제 주최측 상단 노출 광고 (프리미엄 리스팅)
```

## 기술 구현 방향

| 구성 요소 | 기술 | 설명 |
|-----------|------|------|
| 축제 달력 | FullCalendar.js / React Big Calendar | 날짜별 축제 일정 표시 |
| 지도 | Kakao Map API | 지역별 축제 위치 핀 |
| 축제 정보 수집 | 웹 크롤링 + API 연동 | 한국관광공사 API, 지자체 사이트 |
| 숙소/교통 제휴 | 제휴사 API 연동 | 예약 링크 및 수수료 트래킹 |
| 프론트엔드 | Next.js (SEO 최적화) | 반응형 웹 |
| 백엔드 | Node.js + PostgreSQL | API + 축제 데이터 관리 |

## 핵심 기능 상세

### 1. 날짜별 달력
- **달력 뷰**: 월별 달력에 축제가 있는 날짜에 점 표시
- **날짜 선택**: 특정 날짜 클릭 시 그날 열리는 축제 리스트
- **기간 검색**: 2/15~2/17(3일) 선택 시 기간 내 모든 축제 표시
- **D-day 표시**: 축제 시작까지 며칠 남았는지 표시

### 2. 시즌 테마 필터
- **봄**: 벚꽃축제, 유채꽃축제, 매화축제
- **여름**: 물놀이축제, 해변축제, 불꽃축제
- **가을**: 단풍축제, 수확축제, 억새축제
- **겨울**: 빛축제, 눈축제, 얼음축제
- **상시**: 음식축제, 문화축제, 지역축제

### 3. 여행지 매칭
- **지역 선택**: 강릉 클릭 시 강릉 + 강릉 근처(30km 이내) 축제 표시
- **추천 코스**: 축제 + 주변 관광지 + 맛집 (1박 2일 코스)
- **교통편**: 서울에서 출발 시 KTX/버스/렌터카 소요 시간 및 가격
- **숙소 추천**: 축제장 근처 숙소 리스트 (거리순, 가격순)

### 4. 축제 상세 페이지
- **기본 정보**: 축제명, 기간, 위치, 입장료, 주차 가능 여부
- **주요 프로그램**: 공연 일정, 체험 부스, 포토존
- **혼잡도 예측**: 주말 vs 평일, 낮 vs 밤 혼잡도 (과거 데이터 기반)
- **날씨**: 축제 기간 예상 날씨
- **리뷰**: 다녀온 사람들의 후기 (별점, 사진)

### 5. 나만의 축제 캘린더
- **관심 축제 저장**: 가고 싶은 축제를 내 캘린더에 추가
- **알림**: 축제 시작 1주일 전, 3일 전 푸시 알림
- **체크리스트**: 다녀온 축제 체크 및 후기 작성
- **공유**: 친구와 축제 계획 공유

## 경쟁 우위 / 차별화 전략

1. **날짜 우선 접근**: 기존 여행 플랫폼은 장소 중심, 우리는 날짜 중심
2. **축제 특화**: 관광지가 아닌 '축제'에만 집중하여 차별화
3. **원스톱 여행 계획**: 축제 + 숙소 + 교통 + 맛집을 한 곳에서 해결
4. **시즌 테마**: 벚꽃/불꽃 등 감성적인 테마로 여행 욕구 자극

## 타겟 사용자

| 사용자 그룹 | 니즈 | 사용 시나리오 |
|------------|------|---------------|
| **주말 여행자** | 주말에 근교 여행 | 다음 주말 축제 검색 |
| **커플** | 로맨틱한 데이트 | 빛축제, 불꽃축제 찾기 |
| **가족** | 아이와 함께 체험 | 가족 단위 축제 (체험 부스 많은 곳) |
| **관광객** | 한국 문화 체험 | 전통 축제, 지역 특색 축제 |

## 시즌별 인기 축제 예시

| 시즌 | 대표 축제 | 시기 |
|------|----------|------|
| **봄** | 진해 군항제 (벚꽃), 제주 유채꽃축제 | 3월~4월 |
| **여름** | 보령 머드축제, 부산 불꽃축제 | 7월~8월 |
| **가을** | 안동 국제탈춤페스티벌, 단양 단풍축제 | 9월~10월 |
| **겨울** | 평창 눈축제, 청계천 빛초롱축제 | 12월~2월 |

| 리스크 | 대응 방안 |
|--------|-----------|
| 축제 일정 변경 (날씨, 코로나 등) | 한국관광공사 API 자동 동기화 + 사용자 제보 |
| 소규모 축제 정보 부족 | 지자체 협력 + 사용자 제보 시스템 |

| 비성수기 사용률 저하 | 상시 문화 행사, 공연 정보도 추가 |

## 메모

- 축제는 계절성이 강하므로, 시즌별 마케팅 전략 필수 (봄엔 벚꽃 축제 집중 홍보)
- 한국관광공사 API는 공공 데이터라 무료로 사용 가능 → 초기 데이터 확보 용이
- 지자체 관광공사와 협력하면 지역 홍보 예산 지원 가능
- 장기적으로 축제 관련 굿즈 판매 (축제 티켓 사전 판매 등) 가능
- 013번 팝업 헌터와 통합 가능 (도시 팝업 + 지역 축제 통합 플랫폼)
