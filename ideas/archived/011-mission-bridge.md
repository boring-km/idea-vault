## 핵심 아이디어

전국 교회의 단기선교 일정과 지역을 지도에 시각화하여 중복을 방지하고, 선교 후 남은 물품과 실무 노하우를 다음 팀에게 공유하는 선교 자원 최적화 플랫폼.

## 상세 설명

### 컨셉

매년 여름 수천 개의 교회가 단기선교를 떠나지만, 정보가 파편화되어 있어 다음과 같은 문제가 발생한다:

1. **선교 지도**: 전국 교회의 선교 일정과 지역을 지도에 표시 → 특정 국가/지역 중복 방지
2. **물품 나눔 장터**: 선교 후 남은 의약품, 옷, 공연 소품을 다음 팀에게 무료 나눔
3. **노하우 아카이브**: 워십 영상, 인형극 대본, 비자 발급 팁, 현지 연락처 공유
4. **현지 리뷰**: 숙소 상태, 식당 예약 정보, 조심해야 할 문화적 금기 등 최신 정보

### 왜 지금인가

- 전국 6만여 개 교회 중 상당수가 단기선교 진행
- 여름철 특정 국가(태국, 캄보디아 등)에 팀이 몰려 현지 교회가 부담
- SNS에 흩어진 선교 정보를 체계적으로 정리할 필요성 증가
- 코로나 이후 단기선교 재개되며 정보 수요 급증

## 해결하려는 문제

| 문제 | 해결 방식 |
|------|-----------|
| 여름철 특정 국가에 선교팀이 집중 → 현지 혼잡 | 지도 시각화로 일정 중복 확인 가능 |
| 선교 물품(옷, 의약품 등) 버려짐 | 물품 나눔 장터로 다음 팀에게 양도 |
| 비자/렌터카 등 실무 정보가 공유되지 않음 | 국가별 아카이브에 팁과 연락처 정리 |
| 현지 숙소/식당 정보가 최신화되지 않음 | 방문 후 리뷰로 최신 정보 업데이트 |

## 수익 모델

```
[무료: 기본 지도 + 물품 나눔] → [후원 모델: 자발적 기부]
                                  │
                                  ├─ 교회/기관 후원 받기
                                  ├─ 개인 후원자 모집
                                  └─ 사역 보고서로 투명성 확보

프리미엄 콘텐츠:
- 디자인 자료 (현수막 템플릿, PPT 등) 유료 판매 (5,000~20,000원)
- 여행자 보험 제휴 (가입 시 수수료)
- 선교 물품 쇼핑몰 제휴 (구매 시 수수료)
```

## 기술 구현 방향

| 구성 요소 | 기술 | 설명 |
|-----------|------|------|
| 선교 지도 | Google Maps API / Mapbox | 국가별 핀 표시, 일정별 필터링 |
| 물품 장터 | Next.js + PostgreSQL | 사진 업로드, 카테고리별 검색 |
| 아카이브 | 파일 스토리지 (S3) | PDF, 영상, 문서 다운로드 |
| 리뷰 시스템 | 댓글 + 별점 | 국가/도시별 최신 정보 축적 |
| 사용자 인증 | Firebase Auth / NextAuth | 교회 계정 관리 |
| 백엔드 | Node.js / Supabase | API + 실시간 업데이트 |

## 핵심 기능 상세

### 1. 선교 지도
- **일정 등록**: 교회명, 선교지, 기간, 인원 입력
- **시각화**: 2026년 7월 태국 치앙마이 3팀 예정 등 지도에 표시
- **필터링**: 기간별, 국가별, 교단별 검색
- **연락 기능**: 같은 지역 가는 팀끼리 연결 (협업 가능)

### 2. 물품 나눔 장터
- **카테고리**: 의류, 의약품, 공연 소품, 악기, 전자기기 등
- **상태 표시**: 새 제품, 1회 사용, 약간 손상 등
- **배송 방식**: 직거래, 택배, 교회 전달 선택
- **기한 설정**: 언제까지 나눔 가능한지 명시

### 3. 노하우 아카이브
- **자료 유형**: 워십 영상, 인형극 대본, 율동 안무, 가정통신문 템플릿
- **실무 팁**: 비자 발급 절차, 렌터카 업체 연락처, 현지 유심 구매처
- **금기 사항**: 절대 하면 안 되는 행동, 문화적 주의사항
- **다운로드**: 무료 자료 vs 프리미엄 디자인 자료

### 4. 현지 리뷰
- **숙소 리뷰**: 깨끗함, 위치, 가격, WiFi 속도
- **식당 정보**: 단체 예약 가능 여부, 추천 메뉴, 가격대
- **교통**: 공항 픽업 서비스, 현지 교통수단 이용 팁
- **최신성**: 작년 정보는 '1년 전' 표시로 신선도 체크

## 경쟁 우위 / 차별화 전략

1. **선교 특화**: 일반 여행 플랫폼과 달리 선교 맥락에 최적화
2. **커뮤니티 중심**: 교회끼리 자원을 나누는 나눔 문화 강조
3. **정보 축적**: 시간이 지날수록 국가별 노하우가 쌓여 가치 상승
4. **투명성**: 후원금 사용 내역 공개로 신뢰 확보

## 타겟 사용자

| 사용자 그룹 | 니즈 | 사용 시나리오 |
|------------|------|---------------|
| **선교 담당 목사/간사** | 일정 조율, 물품 조달 | 선교 준비 단계에서 정보 수집 |
| **선교팀원** | 현지 정보, 실무 팁 | 출국 전 현지 문화/금기 학습 |
| **단기선교 다녀온 교회** | 물품 나눔, 노하우 공유 | 귀국 후 자료 업로드 |
| **선교 물품 업체** | 마케팅 채널 | 광고 또는 제휴 |

| 리스크 | 대응 방안 |
|--------|-----------|

| 물품 나눔 사기 우려 | 교회 계정 인증, 거래 후기 시스템 |

| 선교 비수기(9~5월) 사용률 저하 | 국내 봉사활동, 해외 장기선교 정보도 확장 |

- [ ] 리뷰 시스템 추가 개발
- [ ] 선교 연합 행사에서 홍보 (교회 네트워크 통해 확산)
- [ ] 교단별 선교부와 파트너십 체결
- [ ] 후원 시스템 구축 및 투명성 보고 체계 마련

## 메모

- 여름 단기선교 시즌(7~8월)이 피크 → 4~6월 준비 기간에 집중 마케팅
- 교회는 신뢰 네트워크가 강하므로, 초기 핵심 교회 확보가 중요
- 물품 나눔은 환경적으로도 의미 있는 메시지 (지속 가능한 선교)
- 장기적으로 장기선교사 지원, 현지 교회와의 파트너십 정보까지 확장 가능
- 선교 이외에 해외 봉사 NGO에도 유용할 수 있음 (기아대책, 월드비전 등)
