## 핵심 아이디어

스마트스토어/쿠팡 셀러 대상으로, 상품 사진 몇 장과 간단한 정보만 입력하면 AI가 판매용 상세페이지 이미지와 카피를 자동 생성해주는 서비스.

## 상세 설명

### 컨셉

온라인 셀러들이 상품을 등록할 때 가장 큰 병목은 상세페이지 제작이다. 디자이너에게 외주를 주면 건당 5~30만원, 템플릿 서비스를 써도 시간이 많이 걸린다. 이를 해결하기 위해:

1. **상품 사진 업로드**: 배경 자동 제거 + 보정
2. **정보 입력**: 상품명, 특징, 가격 등 간단한 정보만 입력
3. **AI 자동 생성**: 업종/카테고리에 맞는 상세페이지 레이아웃 + 마케팅 카피 자동 생성
4. **원클릭 다운로드**: 스마트스토어/쿠팡 규격에 맞는 이미지로 바로 다운로드

### 왜 지금인가

- 이미지 생성 AI(DALL-E, Midjourney 등)의 품질이 상용 수준에 도달
- 국내 온라인 셀러 100만+ 시대, 개인 셀러/소규모 사업자 급증
- 상세페이지 외주 비용 대비 AI 생성 비용이 1/10 이하

## 해결하려는 문제

| 문제 | 해결 방식 |
|------|-----------|
| 상세페이지 외주 비용이 비쌈 (건당 5~30만원) | AI 자동 생성으로 건당 3,000~5,000원 |
| 디자인 감각이 없는 셀러의 직접 제작 어려움 | 검증된 템플릿 + AI 레이아웃 |
| 제작 시간이 오래 걸림 (외주 3~7일) | 5분 내 즉시 생성 |
| 상품 수가 많을 때 일일이 만들기 불가능 | 대량 생성 기능 제공 |

## 수익 모델

```
[무료 체험: 3건] → [건당 결제: 3,000~5,000원] → [월정액: 29,900원 (30건)] → [프로: 59,900원 (무제한)]
                                                       │                           │
                                                       ├─ 기본 템플릿              ├─ 프리미엄 템플릿
                                                       ├─ 로고 워터마크 제거        ├─ 브랜드 커스텀 테마
                                                       └─ 이미지 다운로드          └─ API 연동 (대량)
```

## 기술 구현 방향

| 구성 요소 | 기술 | 설명 |
|-----------|------|------|
| 배경 제거 | rembg / Remove.bg API | 상품 사진 배경 자동 제거 |
| 이미지 생성 | HTML/CSS → 이미지 렌더링 | 템플릿 기반 상세페이지 이미지 생성 |
| 카피 생성 | OpenAI API / Claude API | 마케팅 문구, 특징 설명 자동 작성 |
| 이미지 보정 | Sharp / Pillow | 밝기, 색감, 크기 자동 조정 |
| 프론트엔드 | Next.js | 에디터 UI + 미리보기 |
| 백엔드 | Node.js / Python | 이미지 처리 파이프라인 |

## 경쟁 우위 / 차별화 전략

1. **한국 이커머스 특화**: 스마트스토어, 쿠팡 규격에 최적화된 출력
2. **속도**: 외주 3~7일 vs AI 5분
3. **가격 파괴**: 외주 5~30만원 vs 건당 3,000~5,000원
4. **대량 생성**: 상품 수백 개를 한 번에 처리 가능

## 리스크 및 고려사항

| 리스크 | 대응 방안 |
|--------|-----------|
| AI 생성 이미지 품질이 기대에 못 미침 | 템플릿 기반으로 안정적 품질 보장, AI는 카피에 집중 |
| 디자인 자유도가 제한적 | 에디터에서 수동 편집 기능 제공 |
| 유사 서비스 등장 | 카테고리별 특화 템플릿으로 차별화 |
| 플랫폼별 규격 변경 | 규격 자동 업데이트 시스템 구축 |
