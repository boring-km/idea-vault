## 핵심 아이디어

"이게 무슨 뜻이야?", "이 드립 써도 될까?" → 마케터, 기획자, 브랜드 담당자를 위해 최신 밈과 신조어를 정리하고, 올바른 사용법과 망한 사례까지 알려주는 트렌드 사전.

## 상세 설명

### 컨셉

인터넷 유행은 너무 빨라서 마케터가 캠페인을 기획할 때쯤이면 이미 '구닥다리' 드립이 되기 쉽다. 또한 맥락 없이 쓰면 역효과가 나기도 한다:

1. **밈 위키**: 유행어의 유래, 정확한 뜻, 사용 맥락, 어감 설명
2. **실시간 랭킹**: 지금 커뮤니티에서 가장 핫한 키워드 순위
3. **사용 예시**: 성공한 사례 vs 망한 사례 비교
4. **용례 퀴즈**: "이 상황에 이 드립 써도 될까?" O/X 테스트

### 왜 지금인가

- 브랜드 마케팅에서 밈 활용이 필수 (MZ 타겟팅)
- 밈 하나로 바이럴 성공/실패가 갈림 (맥락 이해 중요)
- 기존 신조어 사전은 너무 느리거나 설명이 불충분
- 마케터, 기획자, 카피라이터의 트렌드 학습 수요 증가

## 해결하려는 문제

| 문제 | 해결 방식 |
|------|-----------|
| 유행어가 너무 빨라 따라잡기 어려움 | 실시간 랭킹 + 주간 트렌드 리포트 |
| 뜻은 알아도 맥락과 어감을 모름 | 유래, 사용 맥락, 어감 상세 설명 |
| 써도 되는지 말아야 하는지 모름 | 성공/실패 사례 + 용례 퀴즈 |
| 나이/세대에 따라 해석이 다름 | 세대별 반응 차이 설명 |

## 기술 구현 방향

| 구성 요소 | 기술 | 설명 |
|-----------|------|------|
| 밈 위키 | Next.js + PostgreSQL | 검색, 카테고리, 태그 시스템 |
| 실시간 랭킹 | 웹 크롤링 (커뮤니티 키워드 수집) | 디시인사이드, 에펨코리아, 트위터 등 |
| 사용자 기여 | 위키 스타일 편집 시스템 | 사용자 제보 + 에디터 검증 |
| 뉴스레터 | Substack / SendGrid | 주간 트렌드 리포트 발송 |
| 퀴즈 시스템 | React 퀴즈 컴포넌트 | O/X, 객관식 문제 |
| 백엔드 | Node.js + PostgreSQL | API + 구독 관리 |

## 핵심 기능 상세

### 1. 밈 위키
- **검색**: 키워드 입력 시 관련 밈 검색 (예: "오히려 좋아")
- **상세 설명**:
  - **유래**: 어디서 왔는가 (드라마, 유튜브, 커뮤니티 등)
  - **뜻**: 정확한 의미
  - **맥락**: 어떤 상황에서 쓰이는가
  - **어감**: 긍정적/부정적/중립적
  - **세대 차이**: 2030은 웃기는데 4050은 이해 못 하는 경우 등
- **태그**: #유머 #비꼼 #자조 #과장 등

### 2. 실시간 랭킹
- **급상승 키워드**: 오늘 가장 많이 쓰인 신조어 Top 10
- **주간 트렌드**: 이번 주에 새로 등장한 밈
- **시들해진 밈**: 이제 쓰면 '구닥다리'로 보이는 밈 (주의)
- **출처 표시**: 커뮤니티별 언급 빈도 그래프

### 3. 성공/실패 사례
- **성공 사례**: 브랜드가 밈을 잘 활용한 캠페인 (예: 배민 카피)
- **실패 사례**: 맥락 없이 써서 비난받은 사례 (예: 정치적 맥락 무시)
- **분석**: 왜 성공했는지/실패했는지 해설
- **교훈**: 이 밈을 쓸 때 주의할 점

### 4. 용례 퀴즈
- **상황 제시**: "신제품 출시 지연을 발표할 때"
- **보기**: "오히려 좋아" vs "~~그것은 제 잘못입니다~~"
- **정답 해설**: 자조적 상황에선 OK, 진지한 사과엔 부적절
- **난이도**: 초급/중급/고급

### 5. 세대별/산업별 필터
- **세대**: 1020 / 2030 / 3040 / 5060
- **산업**: IT/스타트업 / 뷰티/패션 / 식음료 / 게임/엔터
- **톤앤매너**: 친근함 / 유머 / 진지함 / 힙함

## 경쟁 우위 / 차별화 전략

1. **마케터 특화**: 일반 신조어 사전과 달리 '비즈니스 활용' 관점
2. **맥락 중심**: 단순 뜻 풀이가 아닌 사용 맥락과 어감까지
3. **실시간성**: 커뮤니티 크롤링으로 최신 트렌드 빠르게 반영
4. **퀴즈/사례**: 재미있게 학습하고 실전에 적용 가능

## 타겟 사용자

| 사용자 그룹 | 니즈 | 사용 시나리오 |
|------------|------|---------------|
| **마케터** | 캠페인에 밈 활용 | 카피 작성 전 검색 |
| **카피라이터** | 톤앤매너 맞는 유행어 찾기 | SNS 콘텐츠 제작 시 참고 |
| **기획자** | 타겟의 언어 이해 | MZ 타겟 서비스 기획 시 |
| **콘텐츠 크리에이터** | 유행 타는 소재 찾기 | 유튜브/인스타 콘텐츠 아이디어 |

## 콘텐츠 예시

| 밈 | 유래 | 뜻 | 맥락 | 주의사항 |
|----|------|-----|------|---------|
| **오히려 좋아** | 마블 어벤져스 | 나쁜 상황을 긍정적으로 전환 | 자조적 유머 | 진지한 사과엔 부적절 |
| **~하다가 뒤졌어요** | 개그콘서트 | 극단적 과장 표현 | 웃긴 상황 강조 | 실제 사망 관련 맥락엔 금기 |
| **그것은 제 잘못입니다** | 아이언맨(토니 스타크) | 책임 인정하는 척 비꼼 | 누가 봐도 내 잘못 아닌데 억울할 때 | 진짜 사과 상황엔 부적절 |

## 리스크 및 고려사항

| 리스크 | 대응 방안 |
|--------|-----------|
| 유행이 너무 빨라 업데이트 부담 | 커뮤니티 크롤링 자동화 + 사용자 제보 |
| 밈의 정치적/민감한 맥락 | 에디터 검증 + 주의사항 명시 |
| 세대/지역에 따라 해석 다름 | 세대별 반응 차이 설명란 추가 |
| 무료로 볼 수 있는 정보 | 심화 분석/리포트로 차별화 |

## 실행 계획

- [ ] 마케터/카피라이터 20명 인터뷰 (니즈 및 pain point 검증)
- [ ] 밈 100개 초기 데이터베이스 구축
- [ ] 검색 + 위키 스타일 MVP 개발
- [ ] 커뮤니티 키워드 크롤링 자동화
- [ ] 성공/실패 사례 10개 작성
- [ ] 베타 테스트 (마케팅 커뮤니티, 광고 대행사)
- [ ] 주간 트렌드 리포트 뉴스레터 시작
- [ ] 용례 퀴즈 및 프리미엄 기능 추가

## 메모

- 마케터는 '틀리면 안 된다'는 압박이 크므로, 검증된 정보 제공이 핵심
- 밈 하나로 브랜드 이미지가 좌우되므로, 주의사항을 명확히 해야 함
- 뉴스레터 형식이 마케터에게 친숙 (트렌드 리포트 형태)
- 장기적으로 '밈 활용 컨설팅'으로 B2B 확장 가능
- 기업 교육 프로그램 (MZ 세대 이해 워크숍) 진행 가능
