## 핵심 아이디어

인스타그램에 흩어진 팝업스토어 정보를 실시간 지도에 모아서 보여주고, 사용자 제보로 현재 대기 시간을 표시하여 '헛걸음' 없이 효율적으로 핫플을 탐방할 수 있게 하는 서비스.

## 상세 설명

### 컨셉

핫한 팝업스토어나 브랜드 축제를 가고 싶지만:

1. **실시간 지도**: 성수/홍대/강남 등 지역별로 현재 진행 중인 팝업 위치 표시
2. **대기 현황**: 사용자 제보로 '바로 입장 가능', '대기 30팀', '입장 마감' 등 상태 표시
3. **테마 필터**: 뷰티(립스틱 아이콘), 먹거리(햄버거 아이콘), 체험(카메라 아이콘) 등으로 분류
4. **일정 알림**: 관심 브랜드 팝업이 열리면 알림

### 왜 지금인가

- 브랜드 마케팅 전략으로 팝업스토어가 급증
- 성수동, 홍대 등 핫플레이스에 동시다발적으로 팝업 진행
- 인스타에 정보가 흩어져 있어 놓치는 경우 많음
- 대기 시간을 모르고 가서 2시간 줄 서거나, 이미 입장 마감되어 헛걸음

## 해결하려는 문제

| 문제 | 해결 방식 |
|------|-----------|
| 팝업 정보가 인스타에 파편화 | 한 지도에서 모든 팝업 한눈에 보기 |
| 현장 가봐야 대기 시간 알 수 있음 | 실시간 사용자 제보로 대기 현황 표시 |
| 내가 관심 있는 카테고리만 보고 싶음 | 뷰티/먹거리/체험 등 아이콘 필터 |
| 팝업이 언제까지인지 놓침 | D-3 등 종료 임박 표시 및 알림 |

## 수익 모델

```
[무료: 지도 검색 + 대기 현황] → [광고 수익]
                                 │
                                 ├─ 지도 하단 배너 광고
                                 ├─ 행사 주최측 상단 노출 광고
                                 └─ 프리미엄 핀 (특별 아이콘/색상)

프리미엄 기능 (선택):
- 관심 브랜드 알림 무제한 (무료는 3개)
- 팝업 다녀온 후 인증샷 모아보기
- 팝업 체크리스트 (내가 간 팝업 기록)
```

## 기술 구현 방향

| 구성 요소 | 기술 | 설명 |
|-----------|------|------|
| 실시간 지도 | Kakao Map API / Naver Map API | 팝업 위치 핀 표시 |
| 대기 현황 제보 | WebSocket (실시간 업데이트) | 사용자 제보 즉시 반영 |
| 팝업 정보 수집 | 웹 크롤링 + 사용자 제보 | 인스타 해시태그, 공식 사이트 크롤링 |
| 알림 시스템 | FCM (Firebase Cloud Messaging) | 팝업 오픈/종료 임박 푸시 알림 |
| 프론트엔드 | Next.js (반응형 웹) | 모바일 우선 설계 |
| 백엔드 | Node.js + PostgreSQL | API + 실시간 상태 관리 |

## 핵심 기능 상세

### 1. 실시간 지도
- **지역별 보기**: 성수/홍대/강남/명동 등 핫플레이스 탭
- **핀 표시**: 팝업스토어 위치를 지도에 핀으로 표시
- **클러스터링**: 같은 건물에 여러 팝업이 있으면 묶어서 표시
- **거리 표시**: 내 위치에서 걸어서 몇 분 거리인지 표시

### 2. 대기 현황 (크라우드소싱)
- **상태 아이콘**: 🟢 바로 입장, 🟡 대기 10~30분, 🔴 대기 1시간+, ⚫ 입장 마감
- **사용자 제보**: "지금 여기 대기 줄이 어때요?" 버튼 클릭 → 현황 업데이트
- **신뢰도**: 5분 내 제보만 표시, 여러 명이 제보하면 신뢰도 상승
- **제보 리워드**: 제보 시 포인트 적립 (추후 기능 확장 시 활용)

### 3. 테마별 필터
- **뷰티**: 💄 립스틱, 향수, 스킨케어 팝업
- **먹거리**: 🍔 디저트, 음료, 브런치 팝업
- **체험**: 📷 포토존, 게임, VR 체험
- **패션**: 👕 의류, 신발, 액세서리
- **전시**: 🎨 아트, 갤러리, 인터랙티브

### 4. 팝업 상세 페이지
- **기간**: 2026.02.13 ~ 2026.02.20 (D-7 표시)
- **운영 시간**: 평일 11:00~20:00, 주말 10:00~21:00
- **혜택**: 선착순 굿즈, 할인 쿠폰 등
- **사진**: 현장 분위기, 포토존, 전시물 사진
- **리뷰**: 다녀온 사람들의 한 줄 평

### 5. 알림 기능
- **관심 브랜드 등록**: 좋아하는 브랜드 3개 선택
- **오픈 알림**: 등록한 브랜드 팝업이 열리면 푸시
- **종료 임박 알림**: D-3일 때 "곧 종료됩니다" 알림
- **대기 상황 변화**: 대기가 짧아지면 알림 (선택)

## 경쟁 우위 / 차별화 전략

1. **실시간성**: 인스타는 과거 정보, 우리는 '지금 이 순간' 현황
2. **대기 시간 가시화**: 가보기 전에 대기 현황을 알 수 있음
3. **지도 중심**: 동선 계획하기 쉬움 (홍대 3곳 한 번에 돌기)
4. **커뮤니티 기여**: 사용자가 제보하며 함께 만드는 플랫폼

| 리스크 | 대응 방안 |

## 메모

- 팝업스토어는 기간이 짧아 정보 신선도가 생명 → 자동화 크롤링 필수
- 사용자 제보 문화가 정착되면 네트워크 효과 강력 (배달의민족 리뷰처럼)
- 대기 시간 정보는 다른 플랫폼에 없는 차별점 → 핵심 경쟁력
- 인플루언서와 제휴하여 초기 사용자 확보 (팝업 가는 인플루언서들)
- 장기적으로 팝업 주최 대행 서비스로 확장 가능 (B2B)
