## 핵심 아이디어

특정 도메인에 최적화된 Context를 미리 구성해둔 AI 채팅 서비스를 구독제로 제공하고, 일일 사용 횟수 제한 + 추가 과금 모델로 수익화한다.

## 상세 설명

### 컨셉

범용 AI 챗봇(ChatGPT, Claude 등)은 모든 분야를 다루지만, 특정 도메인에서는 깊이가 부족하거나 매번 맥락을 설명해야 하는 불편함이 있다. 이를 해결하기 위해:

1. **도메인별 Context 사전 구성**: 해당 분야의 전문 지식, 용어, 가이드라인, 규정 등을 미리 시스템 프롬프트에 내장
2. **사용자 개인화**: 사용자가 자신의 상태/정보를 등록하면, 매번 설명할 필요 없이 맞춤형 답변 제공
3. **일일 사용 제한 + 추가 과금**: 기본 구독으로 하루 N회 무료 제공, 초과 시 건당 과금

### 왜 지금인가

- 2026년 기준 버티컬 AI 시장이 급성장 중 (연 400% 성장, 2032년 $100B 돌파 전망)
- 범용 AI 대비 도메인 특화 AI가 정확도와 만족도에서 우위
- 구독 경제가 일상화되어 사용자들이 월정액 서비스에 익숙

## 해결하려는 문제

| 문제 | 해결 방식 |
|------|-----------|
| 범용 AI에 매번 배경 설명 필요 | 도메인 Context 사전 구성 |
| 전문 분야 답변 품질 불균일 | 분야별 지식 베이스 + 프롬프트 최적화 |
| 전문가 상담 비용이 비쌈 | 저렴한 구독료로 24시간 접근 가능 |
| 정보 과잉 속 신뢰할 만한 답변 부재 | 검증된 출처 기반 답변 제공 |

## 수익 모델

```
[무료 체험] → [기본 구독: 월 9,900~19,900원] → [프리미엄 구독: 월 29,900원]
                    │                                    │
                    ├─ 하루 5~10회 질문                   ├─ 하루 30~50회 질문
                    ├─ 기본 도메인 1개                    ├─ 도메인 3개까지
                    └─ 추가 질문: 건당 200~500원          └─ 추가 질문: 건당 100~300원
```

- **구독제 (기본)**: 월 정액으로 일일 제한 횟수 내 사용
- **종량제 (추가)**: 일일 제한 초과 시 건당 과금
- **프리미엄 티어**: 높은 횟수 제한 + 우선 응답 + 고급 분석 기능

## 도메인별 서비스 예시

### 예시 1) 피트니스 코치 채팅

> "헬스장에서 어떤 운동을 해야 할지, 기구 사용법, 운동 횟수 기록, 내 신체 상태에 맞는 조언"

- **사전 Context**: 운동 과학, 해부학 기초, 기구별 사용법, 식단 영양 정보
- **사용자 프로필**: 키, 몸무게, 운동 경력, 부상 이력, 목표(벌크업/다이어트/체력)
- **대화 예시**:
  - "오늘 벤치프레스 60kg 5세트 했는데, 다음엔 몇 kg으로 올려야 해?"
  - "허리가 좀 아픈데 스쿼트 대신 할 수 있는 하체 운동 추천해줘"
  - "이번 주 운동 기록 요약해줘"
- **차별점**: 매번 자기 상태를 설명할 필요 없이, 누적 운동 기록과 신체 정보 기반으로 조언

### 예시 2) 반려동물 건강 상담

> "우리 강아지/고양이 상태가 이상한데 병원에 가야 할지, 평소 케어는 어떻게 해야 할지"

- **사전 Context**: 반려동물 종별 건강 정보, 흔한 질병 증상, 예방접종 일정, 영양 정보
- **사용자 프로필**: 반려동물 종류, 나이, 품종, 몸무게, 기존 질환, 예방접종 기록
- **대화 예시**:
  - "우리 강아지가 오늘 밥을 안 먹고 기운이 없어, 어제까지는 괜찮았는데"
  - "고양이 구토를 자주 하는데 정상인 건지 병원을 가야 하는지"
  - "7살 골든리트리버 관절 영양제 추천해줘"
- **차별점**: 반려동물 상태를 지속 추적하여 변화 감지, 병원 방문 판단 보조

### 예시 3) 주니어 개발자 멘토링

> "코드 리뷰, 기술 면접 준비, 커리어 조언, 현재 프로젝트에서 막힌 부분 도움"

- **사전 Context**: 프로그래밍 언어별 베스트 프랙티스, 디자인 패턴, 면접 빈출 주제, 이력서 작성법
- **사용자 프로필**: 기술 스택, 경력, 현재 하는 프로젝트, 목표 회사/직무, 학습 이력
- **대화 예시**:
  - "이 코드 리뷰 좀 해줘, 성능 개선할 부분 있어?"
  - "내일 기술 면접인데 Spring Boot 관련 예상 질문 뽑아줘"
  - "지금 3년차인데 시니어 되려면 뭘 더 공부해야 해?"
- **차별점**: 일반 AI와 달리 사용자의 기술 수준과 목표를 기억하고 맞춤 조언

### 예시 4) 육아 상담

> "아이 발달 단계별 궁금한 점, 수면/식사 문제, 훈육 방법"

- **사전 Context**: 아동 발달 심리학, 연령별 발달 지표, 소아과 기본 상식, 육아 가이드라인
- **사용자 프로필**: 아이 나이, 발달 상태, 알레르기/질환, 양육 환경(맞벌이 등)
- **대화 예시**:
  - "18개월 아이가 아직 걷지를 못해, 걱정해야 할 수준인지"
  - "밤에 계속 깨는데 수면 교육 어떻게 시작해?"
  - "두 돌 아이 식단 추천해줘, 편식이 심해"
- **차별점**: 아이 성장에 따라 Context가 자동 업데이트, 시기별 맞춤 정보

### 예시 5) 세무/회계 도우미

> "프리랜서, 1인 사업자의 세금 신고, 경비 처리, 절세 방법"

- **사전 Context**: 한국 세법, 소득세/부가세 신고 절차, 경비 인정 기준, 최신 세제 변경사항
- **사용자 프로필**: 사업 유형, 연 매출 규모, 사업자 등록 여부, 기존 세무 처리 방식
- **대화 예시**:
  - "프리랜서인데 종합소득세 신고 어떻게 해?"
  - "이번에 노트북 샀는데 경비 처리 가능해?"
  - "올해 세법 바뀐 거 중에 나한테 해당되는 거 있어?"
- **차별점**: 개인 사업 상황에 맞는 절세 전략, 신고 기한 알림

### 예시 6) 식물 케어

> "집에서 키우는 식물 관리법, 병충해 진단, 환경 세팅 조언"

- **사전 Context**: 식물 종별 관리법, 병충해 도감, 실내 환경(빛/습도/온도) 가이드
- **사용자 프로필**: 보유 식물 목록, 집 환경(방향, 조도), 관리 이력
- **대화 예시**:
  - "몬스테라 잎이 노래지는데 원인이 뭘까?"
  - "베란다 서향인데 키우기 좋은 식물 추천해줘"
  - "물 주기 스케줄 만들어줘"
- **차별점**: 사진 업로드로 식물 상태 진단, 계절별 관리 알림

## 기술 구현 방향

| 구성 요소 | 기술 | 설명 |
|-----------|------|------|
| LLM 백엔드 | OpenAI API / Claude API | 핵심 대화 엔진 |
| Context 관리 | RAG (벡터 DB) | 도메인 지식 검색 및 주입 |
| 사용자 프로필 | PostgreSQL + 캐시 | 개인화 정보 저장 |
| 대화 이력 | Redis / DB | 맥락 유지 및 누적 기록 |
| 사용량 제어 | Rate Limiter | 일일 횟수 제한 + 과금 연동 |
| 프론트엔드 | 모바일 앱 (Flutter/RN) | 채팅 UI + 알림 |

## 경쟁 우위 / 차별화 전략

1. **깊이 있는 도메인 특화**: 범용 AI는 넓지만 얕다 → 특정 분야에서 전문가 수준 답변
2. **누적 개인화**: 사용할수록 나를 더 잘 아는 서비스 (대화 이력 + 프로필 기반)
3. **접근성**: 전문가 상담 대비 1/10 비용, 24시간 이용 가능
4. **확장성**: 도메인을 하나씩 추가하며 플랫폼화 가능

## 리스크 및 고려사항

| 리스크 | 대응 방안 |
|--------|-----------|
| AI 할루시네이션으로 잘못된 조언 | 의료/법률/세무는 면책 고지 필수, 출처 표시 |
| 범용 AI의 품질 향상으로 차별점 약화 | 개인화 + 누적 데이터가 핵심 moat |
| 도메인 전문가의 검수 필요 | 초기에 전문가 자문단 구성 |
| 개인정보 보호 | 의료/건강 데이터는 암호화 + 최소 수집 원칙 |

## 실행 계획

- [ ] 시장 조사: 타겟 도메인 1~2개 선정 (가장 수요 높은 분야)
- [ ] MVP 설계: 단일 도메인으로 프롬프트 + RAG 파이프라인 프로토타입
- [ ] 프롬프트 엔지니어링: 도메인 Context 최적화 및 테스트
- [ ] 사용자 테스트: 소규모 베타 테스트 (10~30명)
- [ ] 수익 모델 검증: 구독 + 종량제 하이브리드 모델 A/B 테스트
- [ ] 정식 출시: 앱스토어/플레이스토어 배포

## 메모

- 초기에는 1~2개 도메인에 집중해서 품질을 확보하는 게 중요
- 피트니스/반려동물 같은 일상적이고 반복 질문이 많은 분야가 MVP에 적합
- 의료/법률/세무는 규제 리스크가 있으므로 "참고용" 면책 고지 필수
- 장기적으로 도메인별 전문가 커뮤니티와 연계하면 신뢰도 강화 가능
