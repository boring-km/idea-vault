## 핵심 아이디어

당근마켓/번개장터/중고나라의 거래 데이터를 수집하여 특정 물건(전자기기, 가전, 명품 등)의 실거래 시세를 보여주고, 적정가를 추천하며, 가격 변동 알림을 제공하는 서비스.

## 상세 설명

### 컨셉

중고거래 시 판매자와 구매자 모두 "이 가격이 적정한지" 판단하기 어렵다. 중고차에는 KB차차차 같은 시세 서비스가 있지만, 일반 중고 물건에는 없다:

1. **시세 조회**: 물건명 검색 → 최근 거래 가격 분포, 평균가, 중간가 확인
2. **적정가 추천**: 물건 상태(S/A/B/C급)별 추천 가격 제시
3. **가격 변동 추적**: 특정 물건의 시세 변동 그래프 (신제품 출시 영향 등)
4. **알림**: "아이폰 15 Pro 가격이 X만원 이하로 내려가면 알림"

### 왜 지금인가

- 국내 중고거래 시장 규모 약 30조원, 매년 성장
- 당근마켓 MAU 1,800만+, 중고거래 일상화
- 그러나 가격 판단 도구는 전무 → 명확한 시장 공백
- 데이터가 쌓일수록 가치가 커지는 모델 (데이터 moat)

## 해결하려는 문제

| 문제 | 해결 방식 |
|------|-----------|
| 중고 물건 적정가를 모르겠음 | 실거래 데이터 기반 시세 제공 |
| 너무 비싸게 사거나 싸게 파는 손해 | 적정가 추천 + 시세 범위 안내 |
| 신제품 출시 후 중고가 변동 예측 어려움 | 가격 변동 트렌드 그래프 |
| 좋은 가격의 매물을 놓침 | 목표 가격 알림 기능 |

## 수익 모델

```
[무료: 기본 시세 조회] → [프리미엄: 월 3,900원]
                              │
                              ├─ 상세 가격 분석 (등급별, 지역별)
                              ├─ 가격 알림 무제한
                              ├─ 가격 변동 예측
                              └─ 광고 제거

추가 수익:
- 앱 내 광고 (배너, 네이티브)
- 중고 매입 업체 연결 수수료 (제휴)
- 보험/보증 서비스 연계 (중고 전자기기)
```

## 기술 구현 방향

| 구성 요소 | 기술 | 설명 |
|-----------|------|------|
| 데이터 수집 | 크롤러 (Playwright) | 당근/번개/중고나라 거래 데이터 수집 |
| 데이터 정제 | NLP + 규칙 기반 | 상품명 정규화, 카테고리 분류, 가격 정제 |
| 시세 분석 | Python (pandas, numpy) | 가격 분포, 평균/중간값, 트렌드 분석 |
| 알림 | FCM / 카카오 알림톡 | 목표 가격 도달 시 푸시 알림 |
| 프론트엔드 | React Native / Flutter | 모바일 앱 (검색 + 시세 차트) |
| 백엔드 | FastAPI / Node.js | API 서버 |
| DB | PostgreSQL + Redis | 거래 데이터 + 캐시 |

## 카테고리별 우선순위

| 카테고리 | 거래량 | 가격 변동성 | 시세 니즈 | 우선순위 |
|---------|--------|-----------|----------|---------|
| 스마트폰 (아이폰, 갤럭시) | 매우 높음 | 높음 (신모델 출시) | 매우 높음 | ★★★ |
| 노트북/태블릿 (맥북, 아이패드) | 높음 | 높음 | 높음 | ★★★ |
| 이어폰/헤드폰 (에어팟 등) | 높음 | 중간 | 중간 | ★★☆ |
| 게임기 (PS5, 닌텐도) | 중간 | 중간 | 중간 | ★★☆ |
| 카메라/렌즈 | 중간 | 낮음 | 높음 | ★★☆ |
| 명품 가방/시계 | 중간 | 중간 | 매우 높음 | ★★☆ |
| 가전제품 | 높음 | 낮음 | 중간 | ★☆☆ |

## 경쟁 우위 / 차별화 전략

1. **데이터 moat**: 시간이 지날수록 데이터가 쌓여 정확도 향상
2. **국내 중고거래 플랫폼 특화**: 당근/번개/중고나라 3대 플랫폼 통합
3. **실거래 기반**: 호가가 아닌 실제 거래 완료 가격 기반 분석
4. **간편한 UX**: 물건명만 검색하면 바로 시세 확인

## 리스크 및 고려사항

| 리스크 | 대응 방안 |
|--------|-----------|
| 플랫폼 크롤링 차단 | 적정 빈도 유지, 이용약관 검토, 차단 시 대체 데이터 소스 |
| 거래 완료 vs 호가 구분 어려움 | 거래 완료 표시 기반 필터링, 호가와 분리 표시 |
| 상품 상태에 따른 가격 편차 | 등급별 가격 분류 (S/A/B/C), 평균만이 아닌 분포 표시 |
| 법적 이슈 (데이터 수집 관련) | 공개 데이터만 수집, 개인정보 미수집, 법률 검토 |

## 메모

- 초기에는 전자기기(스마트폰, 노트북)에 집중 → 가격 변동성이 크고 거래량이 많아 데이터 확보 용이
- "이 가격에 사도 될까?" → 이 한 가지 질문에 답하는 것이 핵심 가치
- 당근마켓은 지역별 가격 차이도 분석할 수 있으면 추가 가치
- 장기적으로 중고 매입 업체(셀잇, 민트잇 등)와 제휴하면 수익 다각화 가능
- 중고차의 KB차차차 같은 포지셔닝을 노려야 함
