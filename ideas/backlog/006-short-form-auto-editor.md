## 핵심 아이디어

유튜브 긴 영상 URL만 입력하면 AI가 하이라이트 구간을 자동 추출하고, 세로 크롭 + 자막 생성 + 편집까지 완료하여 릴스/쇼츠/틱톡용 숏폼 영상을 자동 제작하는 서비스.

## 상세 설명

### 컨셉

숏폼(쇼츠, 릴스, 틱톡)은 현재 가장 효과적인 콘텐츠 형식이지만, 긴 영상에서 숏폼을 만드는 작업은 시간이 많이 걸린다. 이를 자동화하여:

1. **URL 입력**: 유튜브/영상 파일 업로드
2. **AI 분석**: 음성 인식(STT) → 텍스트 분석 → 하이라이트/재미있는 구간 자동 선별
3. **자동 편집**: 세로(9:16) 크롭 + 화자 추적 + 자동 자막 + 트렌디한 자막 스타일
4. **다운로드/업로드**: 플랫폼별 최적 규격으로 다운로드

### 왜 지금인가

- 숏폼 콘텐츠 소비량이 매년 2배 이상 증가
- Whisper 등 음성 인식 기술의 정확도가 상용 수준에 도달
- 1인 크리에이터가 숏폼 편집에 가장 큰 시간을 소비
- 편집자 외주 비용 건당 3~10만원은 소규모 크리에이터에게 부담

## 해결하려는 문제

| 문제 | 해결 방식 |
|------|-----------|
| 긴 영상에서 하이라이트 찾는 데 시간 소요 | AI가 음성/텍스트 분석으로 자동 선별 |
| 세로 크롭 + 화자 추적이 수작업 | 얼굴 인식 기반 자동 크롭 |
| 자막 작업이 노동 집약적 | Whisper 기반 자동 자막 + 트렌디한 스타일 |
| 편집자 외주 비용이 비쌈 | 건당 1,000~3,000원으로 해결 |

## 수익 모델

```
[무료: 월 3개] → [건당 결제: 1,000~3,000원] → [월정액: 29,900원 (30개/월)] → [프로: 59,900원 (무제한)]
                                                      │                           │
                                                      ├─ 워터마크 제거             ├─ 프리미엄 자막 스타일
                                                      ├─ 기본 자막 스타일           ├─ 배경음악 라이브러리
                                                      └─ 720p 출력                └─ 1080p + 4K 출력
```

## 기술 구현 방향

| 구성 요소 | 기술 | 설명 |
|-----------|------|------|
| 음성 인식 | Whisper API / faster-whisper | 영상 음성 → 텍스트 (타임스탬프 포함) |
| 하이라이트 선정 | LLM (GPT/Claude) | 텍스트 분석으로 재미있는/중요한 구간 선별 |
| 영상 편집 | FFmpeg + Python (moviepy) | 크롭, 자막 합성, 출력 |
| 얼굴 추적 | MediaPipe / YOLO | 화자 위치 기반 세로 크롭 |
| 자막 렌더링 | ASS/SRT + FFmpeg | 트렌디한 자막 스타일 (단어별 하이라이트 등) |
| 프론트엔드 | Next.js | 업로드 + 편집 미리보기 UI |
| 큐 시스템 | Bull/BullMQ (Redis) | 영상 처리 작업 큐 관리 |

## 경쟁 우위 / 차별화 전략

1. **한국어 자막 품질**: 한국어 특화 음성 인식 + 자연스러운 자막 분절
2. **트렌디한 자막 스타일**: 쇼츠/릴스에서 유행하는 자막 디자인 다수 제공
3. **가격 경쟁력**: 편집자 외주 대비 1/30 수준
4. **속도**: 10분 영상 → 5분 내 숏폼 3~5개 생성

## 리스크 및 고려사항

| 리스크 | 대응 방안 |
|--------|-----------|
| 하이라이트 선정 정확도 | 사용자가 구간 수동 조정 가능하도록 에디터 제공 |
| 영상 처리 서버 비용 | GPU 서버 사용량에 따른 과금, 오프피크 배치 처리 |
| 저작권 이슈 (타인 영상 사용) | 본인 영상만 사용 동의 약관, 신고 시스템 |
| 유사 서비스 경쟁 (OpusClip 등) | 한국어 특화 + 가격 경쟁력으로 차별화 |

## 메모

- OpusClip, Vizard 등 해외 경쟁자가 있지만 한국어 지원이 미흡
- 유튜버뿐 아니라 기업 마케팅 담당자도 주요 타겟
- GPU 서버 비용이 핵심 운영 비용 → 초기에는 Lambda/RunPod 등 서버리스 GPU 활용
- 자막 스타일이 킬러 기능 → 유행하는 스타일을 빠르게 추가하는 것이 중요
