## 핵심 아이디어

반려동물 보호자가 자신의 반려동물 사진·영상을 올리고, 다른 사용자들이 "귀여움 투표"를 하는 소셜 엔터테인먼트 앱. 1:1 대결(토너먼트), 주간 랭킹, 테마별 대회 등을 통해 "우리 아이가 최고"라는 보호자 심리를 자극.

## 상세 설명

### 컨셉

**"인스타에 올리는 건 자랑, 여기선 대결이다"**

- 핵심은 **투표 기반 경쟁**: 단순 피드가 아닌, 1:1 귀여움 대결
- 반려동물 보호자의 "우리 아이가 제일 귀여워" 심리를 게이미피케이션
- 가벼운 엔터테인먼트 — 출퇴근길 5분 킬링타임

### 주요 기능 (MVP)

| 기능 | 설명 |
|------|------|
| **1:1 귀여움 대결** | 랜덤 매칭된 두 반려동물 중 더 귀여운 쪽에 투표 |
| **주간 챔피언** | 주간 투표 1위 반려동물 선정 + 프로필 왕관 뱃지 |
| **테마 대회** | "잠자는 모습", "간식 먹방", "옷 입은 모습" 등 주제별 대회 |
| **반려동물 프로필** | 이름, 종, 나이, 성격 + 사진 갤러리 |
| **피드** | 팔로우한 반려동물들의 일상 사진/영상 |

### 왜 지금인가

- 한국 반려동물 양육 가구 600만+ (전체 가구의 25%)
- 반려동물 관련 콘텐츠는 SNS에서 항상 높은 인게이지먼트
- "펫스타그램" 해시태그 게시물 수천만 개
- MZ세대의 "펫팸족" 트렌드 지속 성장

## 해결하려는 문제

| 문제 | 해결 방식 |
|------|-----------|
| 인스타에선 팔로워 없으면 자랑할 곳이 없음 | 투표 매칭으로 모든 반려동물에게 관심 보장 |
| 반려동물 콘텐츠가 일반 피드에 섞임 | 반려동물 전용 공간 제공 |
| 자랑하고 싶은데 적절한 채널이 없음 | "귀여움 대결"이라는 재미있는 자랑 포맷 |

## 수익 모델

### 핵심 문제: 수익화가 매우 어려움

```
[문제점]
- 핵심 기능(사진 올리기, 투표)에 과금할 수 없음 → 과금하면 사용자 이탈
- 소셜 앱은 사용자 수 = 가치 → 초기에 무조건 무료여야 함
- 반려동물 보호자에게 "귀여움 대결"에 돈을 쓰게 하는 것은 비윤리적으로 느껴질 수 있음
```

### 가능한 수익 모델 (약함)

| 모델 | 예상 수익 | 현실성 |
|------|-----------|--------|
| **인앱 광고** (배너/리워드) | 월 5~30만원 (DAU 1만 기준) | 중 — 사용자 경험 해침 |
| **프리미엄 프로필 꾸미기** | 월 5~20만원 | 낮음 — 지불 의향 극히 낮음 |
| **반려동물 용품 커머스 제휴** | 월 10~50만원 | 중 — 트래픽 확보 전제 |
| **브랜드 협찬 대회** | 건당 50~200만원 | 중 — DAU 수만 이상 필요 |
| **프리미엄 구독** (광고 제거, 대회 참가 등) | 월 3~15만원 | 낮음 — 무료 대안 너무 많음 |

**현실적 시나리오**: DAU 1만 달성 시 광고 + 커머스 제휴로 월 20~80만원 수준. 그러나 DAU 1만 달성 자체가 매우 어려움.

## 수익화 개선 아이디어 (피봇 방향)

단순 "귀여움 자랑"만으로는 수익화가 어렵기 때문에, 아래 방향으로 피봇하면 가능성이 올라갈 수 있음:

### 방향 1: 반려동물 용품 커머스 플랫폼
- 자랑 앱 → "우리 아이가 쓰는 이것" 리뷰 커머스
- 보호자가 올린 사진에 태그된 용품을 바로 구매
- 수익: 커머스 수수료 5~15%

### 방향 2: 반려동물 인플루언서 매칭
- 귀여움 랭킹 상위 반려동물 → 브랜드 협찬 매칭
- 펫 인플루언서 에이전시 모델
- 수익: 매칭 수수료 20~30%

### 방향 3: 반려동물 AI 프로필 생성
- AI로 반려동물 사진을 다양한 스타일로 변환 (왕관, 갑옷, 명화 등)
- 이건 건당 결제 가능 (1,000~3,000원)
- 수익: 직접 과금

## 메모

- **가장 큰 문제는 수익화** — "귀엽다"에 돈을 쓰는 구조가 자연스럽지 않음
- 소셜 앱은 네트워크 효과가 핵심 → 1인 개발로 초기 사용자 모으기 매우 어려움
- Instagram/TikTok이라는 무료 대체재가 너무 강력
- **피봇 없이 순수 자랑 앱으로는 비즈니스 가치 낮음**
- 커머스 또는 AI 프로필 생성을 결합하면 B등급까지 올라갈 가능성 있음
- 반려동물 보험, 건강관리 등 실용 기능과 결합하면 전혀 다른 가치 제안 가능
