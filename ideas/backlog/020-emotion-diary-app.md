## 핵심 아이디어

하루의 감정 상태를 간편하게 기록(탭 몇 번이면 끝)하고, 축적된 감정 데이터를 그래프/캘린더로 시각화하여 **"내 삶의 감정 패턴"**을 한눈에 파악. 어떤 상황에서 어떤 감정을 느꼈는지 데이터를 기반으로 **AI가 간단한 해결 방안이나 대처법을 제안**해주는 앱.

## 상세 설명

### 컨셉

**"상담은 부담스럽고, 혼자 삭이긴 힘들 때 — 조용히 기록하고, 데이터로 나를 이해하자"**

- 핵심은 **감정의 데이터화**: 막연한 감정을 구조화하여 객관적으로 바라보기
- 기록 허들을 극도로 낮춤: 이모지 탭 + 한 줄 메모 (30초면 완료)
- 쌓인 데이터가 가치: 주간/월간/연간 감정 그래프로 삶의 패턴 발견
- AI가 상황에 맞는 간단한 대처법 제시 (전문 상담 대체가 아닌 셀프케어 보조)

### 왜 지금인가

- **멘탈헬스 인식 급상승**: MZ세대 중심으로 "마음 건강도 관리해야" 인식 확산
- 한국 우울증 환자 100만 명 돌파 (2024년), 실제는 훨씬 많을 것으로 추정
- 상담 비용 부담 (회당 5~15만원) → 셀프케어 도구 수요 폭발
- AI 기술 발전으로 감정 분석/맞춤 조언이 저비용으로 가능
- 코로나 이후 정신건강 관심 세계적으로 급증
- 글로벌 멘탈헬스 앱 시장: 2027년 $10.2B (연평균 15.5% 성장)

## 해결하려는 문제

| 문제 | 해결 방식 |
|------|-----------|
| 상담은 비용/시간/심리적 부담이 큼 | 앱으로 혼자 조용히 기록 → 부담 제로 |
| 지인/가족에게 말하면 걱정 끼치는 느낌 | 앱은 판단하지 않고 기록만 해줌 → 안전한 공간 |
| 감정이 막연하고 정리가 안 됨 | 이모지 + 카테고리로 감정 구조화 → 객관화 |
| 내가 왜 힘든지 패턴을 모름 | 주간/월간 감정 그래프로 패턴 시각화 |
| 힘들 때 어떻게 해야 할지 모름 | AI가 상황/감정 기반 간단한 대처법 제시 |
| 좋았던 날도 기억이 안 남 | 감정 히스토리로 좋았던 순간도 기록/회상 |

## 핵심 기능 (MVP)

### 1. 감정 기록 (핵심 — 30초 완료)

```
[오늘의 감정 선택]
😊 좋음  😐 보통  😢 슬픔  😤 화남  😰 불안  😴 지침  🥰 설렘  😌 평온

[강도 슬라이더]
약간 ────●──── 매우

[상황 태그 선택 (복수 가능)]
#직장 #연애 #가족 #건강 #돈 #인간관계 #자존감 #미래불안 #외로움

[한 줄 메모 (선택)]
"오늘 팀장한테 또 혼났다..."

[저장] ← 이게 끝. 30초.
```

### 2. 감정 시각화 (삶의 그래프)

| 시각화 유형 | 설명 |
|-------------|------|
| **감정 캘린더** | 월별 캘린더에 날짜마다 이모지/색상으로 감정 표시 |
| **주간 라인 그래프** | 7일간 감정 점수 변화 추이 |
| **월간 감정 파이차트** | 이번 달 감정 비율 (좋음 40%, 보통 30%, ...) |
| **상황별 감정 히트맵** | "직장" 태그일 때 주로 어떤 감정인지 |
| **연간 감정 타임라인** | 1년간 감정의 큰 흐름 한눈에 |

### 3. AI 인사이트 & 해결 방안

- **패턴 분석**: "최근 2주간 월요일마다 불안 감정이 높아요. 주말→월요일 전환이 스트레스 요인일 수 있어요"
- **상황별 대처법**: "직장 스트레스가 반복되고 있네요. 점심시간 10분 산책이 스트레스 호르몬을 25% 줄여줄 수 있어요"
- **긍정 리마인더**: "지난 주 수요일에 '오랜만에 친구 만나서 좋았다'고 기록하셨어요. 이번 주도 친구와 시간을 보내보는 건 어때요?"
- **위기 감지**: 부정적 감정이 2주 이상 지속되면 전문 상담 안내 (1393 자살예방 상담전화 등)

### 4. 감정 리포트 (주간/월간)

- 매주 일요일 "이번 주 감정 리포트" 푸시 알림
- 가장 많이 느낀 감정, 가장 힘들었던 날, 가장 좋았던 날
- 지난 주 대비 변화 추이
- AI의 한 줄 코멘트

## 수익 모델

```
[무료: 기본 기록 + 캘린더] → [프리미엄: 월 ₩4,900]
        │                          │
        ├─ 일일 감정 기록 (1회)      ├─ 무제한 기록 (하루 여러 번)
        ├─ 감정 캘린더 뷰            ├─ 전체 시각화 (그래프, 히트맵 등)
        ├─ 기본 주간 리포트          ├─ AI 인사이트 & 해결 방안
        └─ 최근 30일 데이터          ├─ 상세 월간/연간 리포트
                                     ├─ 감정 데이터 내보내기 (PDF)
                                     ├─ 무제한 히스토리
                                     └─ 광고 제거
```

### 가격 전략

| 플랜 | 가격 | 타겟 |
|------|------|------|
| **무료** | ₩0 | 가볍게 시작하는 사용자 |
| **월간 구독** | ₩4,900/월 | 꾸준히 관리하고 싶은 사용자 |
| **연간 구독** | ₩39,900/년 (₩3,325/월) | 장기 사용자 (32% 할인) |
| **평생 이용권** | ₩99,000 (1회) | 앱에 확신이 생긴 사용자 |

### 추가 수익원

- **기업 B2B**: 임직원 멘탈케어 솔루션으로 기업 납품 (직원 N명 × 월 ₩2,000)
- **상담사 연계 수수료**: 전문 상담이 필요할 때 온라인 상담 플랫폼 연계 (건당 수수료)
- **감정 스티커/테마 팩**: 캐릭터 이모지, 다크 테마 등 개별 판매 (₩1,000~₩3,000)

## 타겟 사용자

| 세그먼트 | 특징 | 비중 |
|----------|------|------|
| **감정 관리에 관심 있는 MZ세대** | 자기 관리 의식 높음, 앱 친화적 | 45% |
| **직장 스트레스 심한 20~40대** | 만성 스트레스, 번아웃 위험군 | 25% |
| **가벼운 우울/불안 경험자** | 상담까지는 안 가지만 관리 필요 | 20% |
| **일기/기록 습관이 있는 사람** | 기존 일기앱 대체 또는 보완 | 10% |

## 기술 구현 방향

| 구성 요소 | 기술 | 설명 |
|-----------|------|------|
| 프론트엔드 | Flutter | iOS + Android 크로스 플랫폼 |
| 백엔드 | Supabase | 인증, DB, 실시간 구독 |
| AI 분석 | Claude API / GPT API | 감정 패턴 분석, 대처법 생성 |
| 시각화 | fl_chart (Flutter) | 그래프, 캘린더, 히트맵 |
| 결제 | RevenueCat | 구독 관리 |
| 알림 | FCM | 기록 리마인더, 주간 리포트 |
| 로컬 저장 | Hive / SQLite | 오프라인 기록 지원, 프라이버시 |

### 프라이버시 특별 고려

- **로컬 우선 저장**: 감정 데이터는 기본적으로 기기에 저장
- **서버 동기화는 선택**: 백업 원하는 사용자만 클라우드 동기화
- **암호화**: 모든 감정 데이터 E2E 암호화
- **익명 AI 분석**: AI에 보내는 데이터는 익명화 처리
- **데이터 삭제 보장**: 탈퇴 시 모든 데이터 즉시 삭제

## 경쟁 분석

| 서비스 | 강점 | 약점 | 우리의 차별화 |
|--------|------|------|---------------|
| **Daylio** (글로벌 1위) | 간편한 기록, 아름다운 UI | AI 분석 없음, 한국어 지원 약함 | AI 인사이트 + 완벽한 한국 현지화 |
| **Moodfit** | 다양한 멘탈케어 도구 | 기능 너무 많아 복잡 | 극도의 심플함 (기록 30초) |
| **마인드카페** (한국) | 전문 상담사 연결 | 비용 높음, 기록 기능 약함 | 셀프케어 도구 + 필요시 상담 연계 |
| **일기앱들** | 자유로운 텍스트 기록 | 감정 데이터화 불가, 분석 없음 | 감정 구조화 + 시각화 + AI 분석 |

## 경쟁 우위 / 차별화 전략

1. **극도의 간편함**: 30초면 기록 완료 — 허들이 낮아야 매일 씀
2. **감정 데이터화**: 막연한 감정을 이모지 + 강도 + 상황으로 구조화
3. **삶의 그래프**: 한눈에 보는 감정 패턴 — "내가 언제, 왜 힘든지" 객관적 파악
4. **AI 대처법 제시**: 단순 기록을 넘어 실질적 도움 (상담 대체가 아닌 보조)
5. **한국 현지화**: 한국인의 정서, 직장 문화, 관계 특성 반영
6. **프라이버시 최우선**: 감정 데이터는 가장 민감한 개인정보 → 로컬 우선, E2E 암호화

1. **인스타/틱톡 감성 콘텐츠**: "나의 한 달 감정 그래프" 스크린샷 공유 → 바이럴
2. **멘탈헬스 인플루언서 협업**: 심리 유튜버/인스타그래머 리뷰

5. **세계 정신건강의 날(10/10)** 등 시즈널 마케팅
6. **입소문 기능**: 주간 리포트를 이미지로 공유하는 기능 → 자연 바이럴

- **핵심 가치: "기록하는 것만으로도 치유가 된다"** — 표현적 글쓰기(Expressive Writing)의 심리학적 근거
- 감정 기록의 허들을 극도로 낮추는 게 성패의 핵심 (30초 이내)
- AI 조언은 "전문 상담 대체"가 아닌 "셀프케어 보조"로 명확히 포지셔닝
- 프라이버시는 마케팅 포인트가 될 수 있음 ("당신의 감정은 당신만의 것")
- 기록 데이터가 쌓일수록 가치 증가 → 자연스러운 lock-in 효과
- B2B(기업 임직원 멘탈케어)가 장기적으로 가장 큰 수익원이 될 수 있음
- Daylio가 글로벌 성공 → 시장 검증 완료, 한국 현지화 + AI가 차별점
- 감정 데이터는 매우 민감 → 프라이버시 실패하면 앱 자체가 끝남
