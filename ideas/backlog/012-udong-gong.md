## 핵심 아이디어

공방 위치는 네이버 지도에서 찾을 수 있지만, 정작 내가 필요한 장비(CNC, 레이저 커터 등)가 있는지는 일일이 전화해야 한다. 장비 중심으로 공방을 검색하고, 자투리 재료를 나누는 메이커 커뮤니티 플랫폼.

## 상세 설명

### 컨셉

취미로 목공, 가죽공예, 도예를 하고 싶어도 장비를 개인이 구매하기엔 부담스럽다. 공방을 이용하고 싶지만:

1. **장비 필터 검색**: 내 주변에서 3D프린터, CNC, 레이저 커터 보유한 공방만 찾기
2. **상세 정보**: 원데이 클래스 가격, 장비 시간당 대여료, 작업물 갤러리
3. **자투리 마켓**: 공방에서 쓰고 남은 목재, 가죽, 천, 점토 자투리 나눔
4. **예약 시스템**: 장비 사용 시간대 예약 및 결제

### 왜 지금인가

- 메이커 문화 확산으로 DIY/수공예 인구 증가
- 공방 수가 늘고 있지만 정보가 파편화되어 접근성 낮음
- 개인이 고가 장비를 구매하는 것보다 공유 경제 선호
- 자투리 재료는 버려지지만, 초보자에겐 연습용으로 유용

## 해결하려는 문제

| 문제 | 해결 방식 |
|------|-----------|
| 공방 위치는 알아도 보유 장비는 모름 | 장비별 필터 검색 (3D프린터, CNC 등) |
| 일일이 전화로 문의해야 함 | 웹에서 장비, 가격, 예약 가능 시간 확인 |
| 공방마다 가격 체계가 달라 비교 어려움 | 장비별 시간당 평균 가격 표시 |
| 자투리 재료는 버려지는데 초보자는 재료비 부담 | 자투리 나눔 장터로 재료 순환 |

## 수익 모델

```
[무료: 지도 검색 + 자투리 장터] → [공방 멤버십: 월 30,000원]
                                    │
                                    ├─ 예약 관리 시스템 제공
                                    ├─ 공방 프로필 페이지 강조 노출
                                    ├─ 클래스 예약 결제 연동
                                    └─ 작업물 갤러리 무제한 업로드

추가 수익:
- 클래스 예약 수수료 (예약액의 10%)
- 장비 시간 예약 수수료 (예약액의 5%)
- 공방 용품 쇼핑몰 제휴 (재료, 공구 판매 수수료)
```

## 기술 구현 방향

| 구성 요소 | 기술 | 설명 |
|-----------|------|------|
| 공방 지도 | Kakao Map API / Naver Map API | 위치 기반 검색, 거리 계산 |
| 장비 필터링 | PostgreSQL + Full-text Search | 다중 장비 조합 검색 |
| 예약 시스템 | 캘린더 UI (FullCalendar.js) | 시간대별 예약 가능 여부 표시 |
| 자투리 마켓 | Next.js + 이미지 업로드 | 재료 사진, 카테고리, 위치 |
| 결제 | 토스페이먼츠 / 나이스페이 | 클래스/장비 예약 결제 |
| 백엔드 | Node.js + PostgreSQL | API + 예약 관리 로직 |

## 핵심 기능 상세

### 1. 장비 중심 검색
- **필터**: 3D프린터, CNC, 레이저 커터, 전기가마, 재봉틀 등
- **다중 선택**: 3D프린터 + 레이저 커터 둘 다 있는 곳만 표시
- **거리순 정렬**: 내 위치에서 가까운 순서로 나열
- **장비 사진**: 공방이 보유한 장비 실제 사진 및 스펙

### 2. 공방 상세 페이지
- **장비 목록**: 보유 장비와 각각의 시간당 대여료
- **클래스 정보**: 원데이 클래스 일정, 가격, 후기
- **작업물 갤러리**: 공방에서 만든 작품 사진 (포트폴리오)
- **영업 시간**: 평일/주말 시간, 예약 필수 여부
- **리뷰**: 장비 상태, 공방 분위기, 주차 가능 여부

### 3. 예약 시스템
- **장비 예약**: 날짜 + 시간대 선택 (2시간 단위 등)
- **클래스 예약**: 원데이 클래스 신청 및 결제
- **예약 알림**: 예약 1일 전 카카오 알림톡 또는 문자
- **취소 정책**: 공방별 취소 수수료 명시

### 4. 자투리 마켓
- **카테고리**: 목재, 가죽, 천, 점토, 금속, 플라스틱 등
- **사이즈 표기**: 가로x세로x두께, 무게
- **가격**: 무료 나눔 or 저렴한 가격
- **거래 방식**: 공방 방문 수령, 택배 (선택)

### 5. 커뮤니티
- **작업 일지**: 오늘 만든 작품 공유
- **질문 게시판**: 장비 사용법, 재료 추천 등
- **모임**: 같은 관심사 메이커끼리 오프라인 모임

## 경쟁 우위 / 차별화 전략

1. **장비 중심**: 위치가 아닌 '내가 필요한 장비'부터 검색
2. **투명한 가격**: 장비별 시간당 대여료를 명시하여 비교 용이
3. **자투리 경제**: 버려지는 재료를 순환시켜 지속 가능성 강조
4. **커뮤니티**: 공방 검색을 넘어 메이커 문화 허브로 성장

## 타겟 사용자

| 사용자 그룹 | 니즈 | 사용 시나리오 |
|------------|------|---------------|
| **취미 메이커** | 장비 없이 작업하고 싶음 | 주말에 근처 공방에서 CNC 사용 |
| **초보자** | 클래스 수강 후 연습 | 자투리 재료로 저렴하게 연습 |
| **공방 운영자** | 공실 시간 활용, 재료 처리 | 빈 시간대 장비 대여, 자투리 판매 |
| **프리랜서 디자이너** | 프로토타입 제작 | 3D프린터로 시제품 빠르게 제작 |

## 업종별 타겟 공방

| 공방 유형 | 주요 장비 | 니즈 |
|----------|----------|------|
| **목공방** | CNC, 띠톱, 샌딩기 | 장비 대여 + 목재 자투리 판매 |
| **가죽공방** | 재봉틀, 각인기 | 클래스 홍보 + 가죽 자투리 나눔 |
| **도예공방** | 전기가마, 물레 | 도자기 클래스 + 작품 갤러리 |
| **메이커 스페이스** | 3D프린터, 레이저 커터 | 다양한 장비 활용도 극대화 |
| **공예 공방** | 재봉틀, 염색 설비 | 원데이 클래스 + 천 자투리 |

## 리스크 및 고려사항

| 리스크 | 대응 방안 |
|--------|-----------|
| 공방 등록 참여율 저조 | 초기 수작업으로 공방 정보 수집 및 등록 대행 |
| 장비 정보 업데이트 부담 | 공방에게 간단한 관리자 페이지 제공 |
| 자투리 거래 사기 우려 | 공방 계정 인증, 거래 후기 시스템 |
| 예약 노쇼 문제 | 보증금 또는 선결제 제도 도입 |

## 메모

- 메이커 문화가 활발한 성수동, 을지로 중심으로 시작 추천
- 공방 운영자는 마케팅 채널이 부족하므로, 플랫폼 입점 동기 충분
- 자투리 마켓은 초보자에게 '저렴하게 시작할 수 있다'는 심리적 진입장벽 낮춤
- 장기적으로 공방 용품 쇼핑몰 직접 운영 가능 (큐레이션 커머스)
- 010번 예약 관리 시스템과 통합 가능 (공방 예약 특화 버전)
