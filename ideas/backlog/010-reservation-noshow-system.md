## 핵심 아이디어

네일샵, 미용실, 사진 스튜디오, 필라테스 등 소규모 예약제 매장을 위한 간편 예약 관리 시스템. 카카오톡/문자로 예약을 받고, 자동 리마인더를 보내며, 노쇼 시 보증금을 자동 결제하여 노쇼를 방지한다.

## 상세 설명

### 컨셉

소규모 매장 사장님들은 전화/카카오톡으로 예약을 받고 수기로 관리하는 경우가 대부분이다. 노쇼율 15~30%는 직접적인 매출 손실로 이어진다:

1. **간편 예약 링크**: 카카오톡/인스타 프로필에 예약 링크 배치 → 고객이 직접 예약
2. **자동 리마인더**: 예약 1일 전 + 2시간 전 카카오 알림톡 자동 발송
3. **노쇼 보증금**: 예약 시 보증금(5,000~10,000원) 카드 등록, 노쇼 시 자동 결제
4. **대시보드**: 일간/주간 예약 현황, 고객 이력, 매출 통계

### 왜 지금인가

- 예약제 소규모 매장(뷰티, 피트니스, 스튜디오 등) 수십만 개
- 노쇼로 인한 연간 매출 손실이 수조 원 규모로 추산
- 기존 예약 솔루션(네이버 예약 등)은 노쇼 방지 기능이 약함
- 카카오 알림톡 API가 안정화되어 자동 알림 구현 용이

## 해결하려는 문제

| 문제 | 해결 방식 |
|------|-----------|
| 전화/카톡 예약을 수기로 관리 → 실수 발생 | 온라인 예약 시스템으로 자동 관리 |
| 노쇼율 15~30% → 직접 매출 손실 | 보증금 제도 + 자동 리마인더로 노쇼 방지 |
| 예약 확인 전화/문자를 일일이 보냄 | 자동 리마인더 (알림톡) |
| 고객 이력 관리가 안 됨 | 고객별 방문 이력, 메모, 선호도 기록 |

## 수익 모델

```
[무료: 월 30건 예약] → [베이직: 월 15,000원] → [프로: 월 30,000원]
                           │                       │
                           ├─ 예약 무제한            ├─ 예약 무제한
                           ├─ 자동 리마인더          ├─ 자동 리마인더
                           ├─ 기본 캘린더            ├─ 노쇼 보증금 결제
                           └─ 고객 관리 기본         ├─ 고객 관리 상세
                                                   ├─ 매출 리포트
                                                   └─ 직원 스케줄 관리

추가 수익:
- 알림톡 발송 건당 과금 (실비 + 마진)
- 보증금 결제 수수료 (결제액의 3~5%)
```

## 기술 구현 방향

| 구성 요소 | 기술 | 설명 |
|-----------|------|------|
| 예약 페이지 | Next.js (반응형 웹) | 모바일 최적화 예약 폼 |
| 관리자 대시보드 | Next.js | 캘린더 뷰 + 예약/고객 관리 |
| 알림 발송 | 카카오 알림톡 API | 예약 확인 + 리마인더 자동 발송 |
| 결제 (보증금) | 토스페이먼츠 / 나이스페이 | 카드 등록 + 노쇼 시 자동 결제 |
| 백엔드 | Node.js / Python | API 서버 + 스케줄러 |
| DB | PostgreSQL | 예약, 고객, 결제 데이터 |

## 경쟁 우위 / 차별화 전략

1. **노쇼 방지 특화**: 보증금 자동 결제라는 명확한 차별점
2. **초간편 설정**: IT에 익숙하지 않은 사장님도 10분 내 셋업 완료
3. **카카오톡 네이티브**: 고객이 별도 앱 설치 없이 카카오톡으로 예약/알림
4. **저렴한 가격**: 네이버 예약(수수료 기반) 대비 월정액으로 예측 가능한 비용

## 리스크 및 고려사항

| 리스크 | 대응 방안 |
|--------|-----------|
| 보증금 제도에 대한 고객 거부감 | 보증금 없는 옵션도 제공, 노쇼 시에만 차감 안내 |
| 결제 시스템 안정성/보안 | PG사 연동으로 보안 위임, PCI DSS 준수 |
| 경쟁 서비스 (네이버 예약, 테이블링 등) | 노쇼 방지 + 소규모 매장 특화로 차별화 |
| 소상공인의 IT 도구 도입 저항 | 무료 체험 + 극도로 간단한 UX |

## 메모

- 네일샵부터 시작 추천 → 1:1 시술이라 노쇼 타격이 가장 크고, 예약 관리 니즈가 명확
