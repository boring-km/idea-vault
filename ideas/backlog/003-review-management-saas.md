## 핵심 아이디어

네이버/구글/배달의민족/요기요 등 여러 플랫폼에 흩어진 고객 리뷰를 하나의 대시보드에서 모아보고, AI가 답글 초안을 생성해주는 소상공인 전용 SaaS.

## 상세 설명

### 컨셉

소상공인(식당, 카페, 미용실 등)은 네이버 플레이스, 구글 맵, 배달의민족, 요기요, 카카오맵 등 다양한 플랫폼에서 리뷰를 받지만, 각각 로그인해서 확인하고 답글을 다는 것은 시간적으로 큰 부담이다. 이를 해결하기 위해:

1. **리뷰 통합 수집**: 여러 플랫폼의 리뷰를 하나의 대시보드에 실시간 수집
2. **AI 답글 생성**: 리뷰 톤/내용에 맞는 답글 초안을 AI가 자동 작성
3. **감성 분석 리포트**: 긍정/부정 트렌드, 자주 언급되는 키워드 분석
4. **악성 리뷰 알림**: 별점 2점 이하 또는 부정적 리뷰 즉시 알림

### 왜 지금인가

- 리뷰 하나가 매출에 직접적 영향을 미치는 시대 (소비자 93%가 리뷰 확인 후 방문)
- 1인 사장님이 리뷰 관리에 할애할 시간이 절대적으로 부족
- LLM의 답글 생성 품질이 충분히 실용적인 수준에 도달

## 해결하려는 문제

| 문제 | 해결 방식 |
|------|-----------|
| 여러 플랫폼에 흩어진 리뷰 확인이 번거로움 | 하나의 대시보드에서 통합 관리 |
| 답글 작성에 시간이 많이 소요 | AI가 맞춤형 답글 초안 자동 생성 |
| 악성 리뷰에 대한 늦은 대응 | 실시간 알림으로 즉시 대응 가능 |
| 리뷰 트렌드를 파악하기 어려움 | 감성 분석 + 키워드 분석 리포트 제공 |

## 수익 모델

```
[무료 체험 14일] → [베이직: 월 19,900원] → [프로: 월 39,900원] → [프리미엄: 월 49,900원]
                        │                        │                        │
                        ├─ 플랫폼 2개 연동         ├─ 플랫폼 5개 연동        ├─ 플랫폼 무제한
                        ├─ AI 답글 월 50건         ├─ AI 답글 무제한         ├─ AI 답글 무제한
                        └─ 기본 리포트             ├─ 상세 리포트            ├─ 상세 리포트 + 경쟁사 분석
                                                  └─ 카카오 알림톡 연동      └─ 다점포 관리 (최대 10개)
```

## 기술 구현 방향

| 구성 요소 | 기술 | 설명 |
|-----------|------|------|
| 리뷰 수집 | 크롤러 (Playwright/Puppeteer) | 각 플랫폼 리뷰 정기 수집 |
| AI 답글 | OpenAI API / Claude API | 리뷰 톤에 맞는 답글 생성 |
| 감성 분석 | LLM 기반 분류 | 긍정/부정/중립 + 키워드 추출 |
| 알림 | 카카오 알림톡 API | 악성 리뷰 즉시 알림 |
| 프론트엔드 | Next.js | 대시보드 UI |
| 백엔드 | Node.js / Python | API 서버 + 크롤링 스케줄러 |
| DB | PostgreSQL | 리뷰 데이터 + 사용자 정보 |

## 경쟁 우위 / 차별화 전략

1. **한국 플랫폼 특화**: 네이버 플레이스, 배민, 요기요 등 국내 플랫폼 중심 (해외 도구는 미지원)
2. **AI 답글의 자연스러움**: 업종별 말투/톤 프리셋 (식당, 카페, 미용실 등)
3. **저렴한 가격**: 기존 리뷰 관리 대행 월 30~100만원 대비 1/10 수준
4. **간편한 UX**: IT에 익숙하지 않은 사장님도 모바일에서 바로 사용 가능

## 리스크 및 고려사항

| 리스크 | 대응 방안 |
|--------|-----------|
| 플랫폼 크롤링 차단 | 공식 API 우선 사용, 크롤링은 적정 빈도 유지 |
| 플랫폼 약관 위반 가능성 | 법률 검토, 사용자 계정 연동 방식 고려 |
| AI 답글의 부적절한 톤 | 사장님이 최종 확인 후 게시하는 워크플로우 |
| 경쟁 서비스 등장 | 빠른 시장 진입 + 업종별 특화로 moat 구축 |

## 실행 계획

- [ ] 타겟 업종 1~2개 선정 (식당/카페 추천)
- [ ] 네이버 플레이스 + 구글 맵 리뷰 크롤링 프로토타입
- [ ] AI 답글 생성 프롬프트 최적화 (업종별)
- [ ] MVP 대시보드 개발 (리뷰 목록 + 답글 생성)
- [ ] 소상공인 10곳 베타 테스트
- [ ] 배민/요기요 연동 추가
- [ ] 유료 전환 및 마케팅

## 참고 자료

- 국내 소상공인 수 약 700만 (통계청)
- 소비자 93%가 온라인 리뷰를 확인 후 매장 방문 결정
- 리뷰 관리 대행 시장 규모 확대 중

## 메모

- 식당/카페부터 시작해서 미용실, 병원, 숙박 등으로 확장
- 초기에는 네이버 플레이스 + 구글 맵 2개 플랫폼만 지원해도 충분
- 사장님들은 앱보다 카카오톡으로 알림 받는 것을 선호 → 카카오 알림톡 연동 필수
- 장기적으로 리뷰 데이터 기반 컨설팅 서비스로 확장 가능
