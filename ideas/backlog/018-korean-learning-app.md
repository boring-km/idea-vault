## 핵심 아이디어

귀여운 자체 캐릭터(예: 한국 전통 동물 모티브 - 호랑이, 토끼, 삽살개 등)가 한국 일상 시나리오를 안내하며 "진짜 한국어"를 가르치는 미니멀 앱. 교과서 문장이 아닌, 편의점에서/카페에서/지하철에서 실제로 쓰는 표현을 캐릭터 대화로 배운다.

## 상세 설명

### 컨셉

**"Duolingo는 너무 교과서적이고, 다른 앱은 너무 복잡해"**

- 핵심은 **미니멀**: 하루 5분, 한 가지 상황, 한 가지 표현
- 캐릭터가 스토리를 이끌어가며 자연스럽게 학습
- 모든 콘텐츠가 자체 제작 → 저작권 이슈 완전 제로

### 캐릭터 세계관

| 캐릭터 | 모티브 | 성격 | 담당 영역 |
|--------|--------|------|-----------|
| **호돌이** | 호랑이 | 씩씩하고 직설적 | 반말, 감탄사, 슬랭 |
| **달토** | 토끼 | 예의 바르고 다정 | 존댓말, 공손 표현 |
| **뭉이** | 삽살개 | 느긋하고 웃김 | 유머, 의성어/의태어 |

- 캐릭터들이 한국 일상 시나리오를 연기하며 대화
- 학습자는 대화 속에서 표현을 자연스럽게 흡수
- 캐릭터 성장 시스템: 학습할수록 캐릭터가 성장하고 꾸미기 가능

### 왜 지금인가

- 한국어 학습 시장 연평균 25.1% 성장 (2034년 $67B)
- Duolingo 한국어 학습자 1,740만 명 → 시장 검증 완료
- 기존 앱들의 "교과서적 접근"에 불만인 사용자층 존재
- AI(LLM)로 대화 연습 기능을 저비용으로 구현 가능
- 캐릭터 IP는 굿즈/스티커/이모지 등 확장 수익원

## 해결하려는 문제

| 문제 | 해결 방식 |
|------|-----------|
| 교과서 한국어 ≠ 실제 한국어 | 편의점, 카페, 지하철 등 실제 상황 시나리오로 학습 |
| 학습 동기 유지 어려움 | 귀여운 캐릭터 성장 + 스토리 진행으로 지속 동기 |
| 존댓말/반말 혼란 | 캐릭터별로 존댓말(달토)/반말(호돌이) 자연 체득 |
| 기존 앱이 너무 복잡 | 하루 5분, 한 상황, 한 표현 → 극도의 미니멀 |
| 뉘앙스 이해 부족 | "~거든요 vs ~잖아요" 같은 차이를 캐릭터 대화 문맥으로 |

## 핵심 기능 (MVP)

### 1. 데일리 시나리오 (핵심)
- 매일 1개의 한국 일상 시나리오 제공
- 캐릭터 대화 형태로 표현 학습
- 예시: "편의점에서 삼각김밥 데워달라고 할 때"
  - 호돌이: "이거 데워주세요~"
  - 달토: "혹시 이거 전자레인지에 데워주실 수 있을까요?"
  - → 같은 상황, 반말 vs 존댓말 차이를 자연스럽게 체감

### 2. 한 줄 퀴즈
- 시나리오 학습 후 간단한 퀴즈
- "이 상황에서 뭐라고 할까?" → 선택지 중 자연스러운 표현 고르기
- 틀려도 캐릭터가 귀엽게 격려

### 3. AI 프리톡 (선택)
- 캐릭터와 자유 대화 연습 (AI 기반)
- 학습한 표현을 실제로 써보는 연습
- 예: 뭉이에게 "오늘 뭐 먹을까?" 대화 시작

### 4. 표현 카드 수집
- 배운 표현이 귀여운 카드로 저장
- 복습 시 카드 넘기며 확인
- 카드 수집 → 캐릭터 꾸미기 아이템 해금

## 수익 모델

```
[무료: 일 1개 시나리오] → [프리미엄: 월 $4.99]
        │                        │
        ├─ 데일리 시나리오 1개      ├─ 무제한 시나리오
        ├─ 기본 퀴즈              ├─ AI 프리톡
        └─ 표현 카드 수집          ├─ 캐릭터 꾸미기 전체 해금
                                  ├─ 오프라인 모드
                                  └─ 광고 제거
```

### 추가 수익원
- **캐릭터 꾸미기 아이템**: 개별 구매 ($0.99~$2.99)
- **스티커/이모지 팩**: 메신저용 캐릭터 스티커 판매
- **캐릭터 굿즈**: 장기적으로 IP 라이선싱 (스티커, 키링 등)

## 기술 구현 방향 (미니멀 스택)

| 구성 요소 | 기술 | 설명 |
|-----------|------|------|
| 프론트엔드 | Flutter | iOS + Android 크로스 플랫폼, 1인 개발 최적 |
| 백엔드 | Supabase (BaaS) | 인증, DB, 스토리지 올인원 → 서버 관리 최소화 |
| AI 대화 | Claude API | 캐릭터 AI 프리톡, 문법 해설 |
| 콘텐츠 | JSON/마크다운 정적 파일 | 시나리오 데이터, 앱 번들에 포함 |
| 결제 | RevenueCat | 인앱 구독 관리 |
| 분석 | Firebase Analytics | 무료, 충분한 기능 |

## 경쟁 우위 / 차별화 전략

1. **저작권 이슈 제로**: 모든 콘텐츠 자체 제작, 법적 리스크 없음
2. **캐릭터 IP**: Duolingo의 올빼미처럼 브랜드 아이덴티티 + 굿즈 확장
3. **극도의 미니멀**: 하루 5분, 부담 없는 학습 → 리텐션 극대화
4. **살아있는 한국어**: 교과서가 아닌 실제 상황 표현에 집중
5. **낮은 가격**: 월 $4.99 → 경쟁 앱 대비 진입장벽 낮음

## 메모

- 핵심 가치: **"귀엽고, 짧고, 진짜 쓸 수 있는 한국어"**
- Duolingo 올빼미처럼, 캐릭터가 앱의 얼굴이 되어야 함
- MVP는 시나리오 50개 + 퀴즈 + 카드 수집으로 충분 (AI 프리톡은 v2)

- 캐릭터 IP가 자리잡으면 굿즈/스티커가 앱 수익보다 클 수 있음
- 가격은 월 $4.99로 낮게 시작 → 볼륨 우선 전략
