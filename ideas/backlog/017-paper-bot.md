## 핵심 아이디어

"논문은 읽어야 하는데 너무 길고 영어라 힘들어" → PDF 링크나 파일을 업로드하면 AI가 핵심 내용을 구조적으로 요약하고, 챗봇으로 "이 실험의 변수가 뭐야?" 같은 추가 질문에 답변하는 서비스.

## 상세 설명

### 컨셉

연구자, 대학원생, 학부생은 한 학기에 수십~수백 편의 논문을 읽어야 하지만:

1. **구조적 요약**: PDF 링크 입력 → 연구주제, 방법론, 주요 결과, 결론으로 요약
2. **난이도 조절**: 초등학생용 / 고등학생용 / 전공자용 등 요약 깊이 선택
3. **챗봇 질문**: 요약본을 보고 "이 실험의 통제변수는?" 같은 추가 질문 가능
4. **메모 & 인용**: 요약에 메모 추가, APA/MLA 형식 인용구 자동 생성

### 왜 지금인가

- 대학원생, 연구자의 논문 읽기 부담 증가
- arXiv, PubMed 등 오픈 액세스 논문 급증
- AI (GPT-4, Claude) 기술로 논문 이해도 높은 요약 가능
- 기존 번역기로는 논문 특유의 구조와 맥락 이해 어려움

## 해결하려는 문제

| 문제 | 해결 방식 |
|------|-----------|
| 논문이 너무 길어 핵심 파악 어려움 | 구조적 요약으로 빠르게 이해 |
| 영어 논문 읽기 부담 | 한국어로 명쾌하게 요약 |
| 전공 용어 이해 안 됨 | 난이도 조절 (쉬운 표현으로 재설명) |
| 특정 부분만 더 알고 싶음 | 챗봇으로 추가 질문 |
| 인용 형식 작성 번거로움 | APA/MLA 자동 생성 |

## 수익 모델

```
[무료: 요약 3건/월] → [베이직: 월 9,900원] → [프로: 월 19,900원]
                       │                       │
                       ├─ 요약 30건/월            ├─ 무제한 요약
                       ├─ 챗봇 질문 50회         ├─ 무제한 챗봇 질문
                       ├─ 메모 저장              ├─ 메모 + 태그
                       └─ APA 인용 생성          ├─ 다중 논문 비교
                                               ├─ 팀 공유 기능
                                               └─ 커스텀 요약 템플릿

학생 할인: 50% (학교 이메일 인증)
기업 라이센스: 협의 (R&D 팀용)
```

## 기술 구현 방향

| 구성 요소 | 기술 | 설명 |
|-----------|------|------|
| PDF 파싱 | PyPDF2 / pdfplumber | PDF에서 텍스트 추출 |
| 논문 구조 인식 | NLP (섹션 인식) | Abstract, Method, Result, Conclusion 분리 |
| AI 요약 | GPT-4 / Claude API | 구조적 요약 생성 |
| 챗봇 | RAG (Retrieval-Augmented Generation) | 논문 내용 기반 Q&A |
| 번역 | DeepL API / GPT-4 | 영어 → 한국어 자연스러운 번역 |
| 프론트엔드 | Next.js + React | PDF 업로드, 요약 보기, 챗봇 UI |
| 백엔드 | Python (FastAPI) + PostgreSQL | API + 요약 데이터 저장 |

## 핵심 기능 상세

### 1. 구조적 요약
- **섹션별 요약**:
  - **연구 주제**: 무엇을 연구했나 (1문장)
  - **배경**: 왜 이 연구가 필요한가 (3문장)
  - **방법론**: 어떻게 연구했나 (실험 설계, 데이터, 도구)
  - **주요 결과**: 무엇을 발견했나 (핵심 수치, 그래프 설명)
  - **결론**: 연구의 의미와 한계 (2~3문장)
- **시각화**: 연구 흐름도 (플로우차트)
- **키워드 추출**: 핵심 개념 5개

### 2. 난이도 조절
- **초등학생용**: "과학자들이 물고기가 색깔을 보는 방법을 연구했어요"
- **고등학생용**: "연구팀은 어류의 시각 인지 능력을 실험을 통해 분석했습니다"
- **전공자용**: "본 연구는 teleost fish의 cone cell 분포를 spectroscopy로 측정했다"
- **원문 수준**: 논문 원문과 동일한 전문 용어 유지

### 3. 챗봇 Q&A
- **질문 예시**:
  - "이 실험의 통제변수는 뭐야?"
  - "결과의 p-value가 뭐야?"
  - "저자가 제시한 한계점은?"
- **답변**: 논문에서 해당 부분을 찾아 인용하며 설명
- **페이지 표시**: "논문 3페이지 참고"

### 4. 메모 & 하이라이트
- **형광펜**: 요약본에서 중요한 부분 하이라이트
- **메모**: "이 방법론 우리 연구에 적용 가능" 등 메모 추가
- **태그**: #방법론 #관련연구 #참고할것 등 태그로 분류
- **폴더**: 논문을 주제별로 폴더에 정리

### 5. 인용 자동 생성
- **APA 형식**:
  ```
  Smith, J. (2025). The role of AI in education. Journal of Learning, 12(3), 45-67.
  ```
- **MLA 형식**:
  ```
  Smith, John. "The Role of AI in Education." Journal of Learning, vol. 12, no. 3, 2025, pp. 45-67.
  ```
- **복사 버튼**: 클릭 한 번에 클립보드 복사

### 6. 다중 논문 비교 (프로)
- **비교 테이블**: 3개 논문의 방법론, 결과 나란히 비교
- **공통점/차이점**: AI가 자동으로 분석
- **종합 요약**: "3편 논문 모두 X를 지지하지만, Y에 대해선 의견이 갈림"

## 경쟁 우위 / 차별화 전략

1. **구조적 요약**: 단순 번역이 아닌 논문 구조에 맞춘 요약
2. **챗봇 Q&A**: 요약 후 추가 질문으로 깊이 있는 이해
3. **난이도 조절**: 전공자부터 비전공자까지 모두 활용
4. **학술 특화**: 논문 특유의 구조(Abstract, Method 등) 이해

## 타겟 사용자

| 사용자 그룹 | 니즈 | 사용 시나리오 |
|------------|------|---------------|
| **대학원생** | 문헌 조사 시간 단축 | 학기 중 논문 30편 빠르게 읽기 |
| **연구자** | 최신 연구 동향 파악 | arXiv 최신 논문 매일 체크 |
| **학부생** | 과제/리포트 작성 | 논문 이해하고 인용하기 |
| **R&D 팀** | 기술 조사 | 경쟁사 특허/논문 분석 |

## 대상 논문 플랫폼

| 플랫폼 | 분야 | 특징 |
|--------|------|------|
| **arXiv** | 물리/수학/CS | 무료 오픈 액세스 |
| **PubMed** | 의학/생명과학 | 의학 논문 최대 DB |
| **IEEE Xplore** | 공학 | 전기/전자/컴퓨터 |
| **Google Scholar** | 전 분야 | 검색 엔진 |

## 리스크 및 고려사항

| 리스크 | 대응 방안 |
|--------|-----------|
| PDF 파싱 실패 (이미지 스캔본 등) | OCR 기술 병행 (Tesseract) |
| AI 요약 정확도 문제 | 사용자 피드백으로 지속 개선 |
| 저작권 (논문 전문 저장) | 요약본만 저장, 원문은 링크만 제공 |
| 복잡한 수식/그래프 처리 | 수식은 LaTeX 변환, 그래프는 캡션 요약 |

## 메모

- 대학원생은 가격 민감 → 학생 할인 필수
- 논문 요약은 법적으로 '공정 이용' 범위 → 전문 저장만 피하면 OK
- arXiv는 API 제공 → 최신 논문 자동 수집 가능
- 연구실 단위로 팀 구독 유도 (교수 1명이 결제하면 연구실 전체 사용)
- 장기적으로 '논문 작성 도우미' 기능 추가 (초고 작성, 문법 검사)
