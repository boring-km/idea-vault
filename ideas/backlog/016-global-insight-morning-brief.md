## 핵심 아이디어

"해외 트렌드를 먼저 알고 싶지만 영어 기사 읽을 시간 없어" → 매일 아침 7시, 해외 핵심 기사 5개를 Fact(팩트), Meaning(의미), Action(적용점)으로 구조화하여 3분 만에 읽을 수 있게 큐레이션.

## 상세 설명

### 컨셉

해외 테크 미디어(TechCrunch, The Verge, Fast Company 등)의 기사를 읽고 싶지만:

1. **모닝 큐레이션**: 매일 아침 핵심 기사 5개만 엄선
2. **3단 요약**:
   - **Fact**: 무슨 일이 일어났는가 (50자)
   - **Meaning**: 왜 중요한가, 트렌드는 무엇인가 (100자)
   - **Action**: 내가/우리 팀이 적용할 점은? (100자)
3. **감정 분석**: 기사의 분위기를 아이콘으로 표시 (🚀 혁신, ⚠️ 우려, 🔥 논란)
4. **관심 분야 선택**: 테크/디자인/비즈니스/AI 등 관심 분야만 받기

### 왜 지금인가

- 해외 정보가 빠를수록 경쟁 우위 (선제적 의사결정)
- 번역기는 어색하고, 직접 읽기엔 시간 부족
- 정보 과잉 시대에 '큐레이션'의 가치 상승
- 스타트업, 마케터, 기획자는 해외 트렌드 학습 필수

## 해결하려는 문제

| 문제 | 해결 방식 |
|------|-----------|
| 영어 기사 읽기 부담스러움 | 한국어로 명쾌하게 요약 |
| 뭐가 중요한 기사인지 모름 | 에디터가 핵심 5개만 엄선 |
| 단순 번역은 맥락이 없음 | Fact-Meaning-Action 구조로 인사이트 제공 |
| 너무 많은 정보에 압도됨 | 3분이면 다 읽을 수 있는 분량 |

```
기업용 라이센스:

```

## 기술 구현 방향

| 구성 요소 | 기술 | 설명 |
|-----------|------|------|
| 뉴스 수집 | RSS Feed + 웹 크롤링 | TechCrunch, The Verge 등 주요 미디어 |
| AI 요약 | GPT-4 / Claude API | Fact-Meaning-Action 구조로 요약 |

| 구독 관리 | Stripe / 토스페이먼츠 | 결제 및 구독 관리 |

## 핵심 기능 상세

### 1. 모닝 큐레이션 (매일 5개)
- **기사 선정 기준**:
  - 혁신성: 새로운 기술/트렌드
  - 영향력: 산업에 미칠 파급력
  - 시의성: 오늘 꼭 알아야 할 소식
- **다양성**: AI, 디자인, 비즈니스, 스타트업 등 골고루
- **독자 투표**: 오늘 기사 중 가장 유용했던 것 투표

### 2. 3단 구조화 요약
- **Fact (팩트)**:
  - 예: "OpenAI, GPT-5 출시 발표. 추론 능력 2배 향상"
- **Meaning (의미)**:
  - 예: "AI 경쟁이 추론 능력으로 이동. 단순 생성 → 복잡한 문제 해결로 진화"
- **Action (적용점)**:
  - 예: "우리 서비스에 AI 적용 시, 단순 답변보다 맥락 이해형 기능 고려 필요"

### 3. 감정 아이콘
- 🚀 **혁신**: 새로운 기술/제품 출시
- ⚠️ **우려**: 규제, 윤리적 문제 제기
- 🔥 **논란**: 업계 갈등, 비판
- 💡 **인사이트**: 트렌드 분석, 전문가 의견
- 📊 **데이터**: 시장 조사, 통계 발표

### 4. 관심 분야 선택
- **테크**: AI, 소프트웨어, 하드웨어
- **디자인**: UI/UX, 그래픽, 브랜딩
- **비즈니스**: 스타트업, 마케팅, 투자
- **소비자 트렌드**: 라이프스타일, 리테일
- **우주/미래**: 우주산업, 미래학

### 5. 주간 심화 리포트 (프리미엄)
- **이번 주 핵심 트렌드**: 5개 기사를 관통하는 큰 흐름
- **심화 분석**: 해당 트렌드가 한국 시장에 미칠 영향
- **참고 자료**: 추가 읽을거리, 리포트 링크
- **전문가 코멘트**: 국내 전문가 인터뷰

### 6. 아카이브 & 검색
- **날짜별 보기**: 지난달 특정일 뉴스 찾기
- **키워드 검색**: "메타버스" 관련 기사만 모아보기
- **북마크**: 나중에 다시 읽을 기사 저장
- **공유**: 팀원에게 기사 공유 기능

## 경쟁 우위 / 차별화 전략

1. **구조화 요약**: 단순 번역이 아닌 Fact-Meaning-Action 프레임워크
2. **에디터 큐레이션**: AI만으로는 불가능한 '중요도 판단'
3. **3분 소화**: 바쁜 아침에 부담 없이 읽을 수 있는 분량
4. **적용 중심**: '알았다'에서 끝이 아닌 '어떻게 쓸까' 제시
