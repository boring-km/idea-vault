## 핵심 아이디어

계약서 PDF/사진을 업로드하면 AI가 불리한 조항, 빠진 조항, 주의할 점을 분석해서 알기 쉽게 설명해주는 서비스. 부동산 임대차, 프리랜서 용역, 근로계약 등 유형별로 특화된 검토를 제공한다.

## 상세 설명

### 컨셉

대부분의 사람들은 계약서를 제대로 읽지 않거나, 읽어도 어떤 조항이 불리한지 판단하기 어렵다. 변호사 상담은 30분에 5~10만원으로 비용 부담이 크다:

1. **계약서 업로드**: PDF, 이미지, 사진 촬영 등 다양한 형태 지원
2. **OCR + AI 분석**: 텍스트 추출 → 계약서 유형 자동 분류 → 조항별 분석
3. **리포트 제공**: 주의 조항(빨강), 확인 필요(노랑), 양호(초록) 신호등 표시
4. **개선 제안**: 불리한 조항에 대한 수정 제안 문구 제공

### 왜 지금인가

- LLM의 법률 문서 이해 능력이 크게 향상
- 전세 사기 등으로 계약서 검토에 대한 사회적 관심 증가
- 리걸테크 시장 급성장 (2030년 $355B 전망)
- 비용 대비 접근성이 압도적으로 높은 솔루션 가능

## 해결하려는 문제

| 문제 | 해결 방식 |
|------|-----------|
| 계약서 내용이 어려워 이해 못함 | AI가 쉬운 말로 풀어서 설명 |
| 어떤 조항이 불리한지 모름 | 위험도별 색상 표시 + 상세 설명 |
| 변호사 상담 비용이 비쌈 | 건당 5,000~15,000원으로 해결 |
| 빠진 조항을 모르고 계약 | 필수 포함 조항 체크리스트 제공 |
| 전세 사기 등 계약 피해 불안 | 등기부등본 확인 가이드, 위험 신호 감지 |

## 수익 모델

```
[무료: 요약만 제공] → [기본 검토: 건당 5,000원] → [상세 검토: 건당 15,000원] → [월정액: 29,900원]
                          │                          │                           │
                          ├─ 조항별 위험도 분석        ├─ 수정 제안 문구 제공       ├─ 무제한 검토
                          └─ 빠진 조항 체크리스트      ├─ 비교 분석 (표준계약서 대비) ├─ 전문가 상담 연결
                                                     └─ PDF 리포트 다운로드       └─ 계약서 보관함
```

## 계약서 유형별 지원

| 유형 | 주요 검토 포인트 | 우선순위 |
|------|-----------------|---------|
| **부동산 임대차 (전/월세)** | 특약사항, 보증금 반환 조건, 계약 해지 조건, 수리 의무 | ★★★ |
| **프리랜서 용역 계약** | 대금 지급 조건, 저작권 귀속, 위약금, 업무 범위 | ★★★ |
| **근로계약서** | 급여, 수습기간, 퇴직금, 경업금지, 비밀유지 | ★★☆ |
| **투자 계약 (주주간)** | 의결권, 희석 방지, 청산 우선권, 동반매각 | ★★☆ |
| **이용약관 (서비스)** | 개인정보, 환불 정책, 면책 조항 | ★☆☆ |

## 기술 구현 방향

| 구성 요소 | 기술 | 설명 |
|-----------|------|------|
| OCR | Tesseract / Google Vision API | 이미지/PDF에서 텍스트 추출 |
| 문서 파싱 | PyPDF2 / pdfplumber | PDF 구조 분석 |
| AI 분석 | Claude API / GPT API | 계약서 유형 분류 + 조항 분석 |
| 법률 지식 | RAG (벡터 DB) | 관련 법률/판례 검색 및 참조 |
| 프론트엔드 | Next.js | 업로드 + 분석 결과 뷰어 |
| 백엔드 | Python (FastAPI) | OCR + AI 분석 파이프라인 |
| DB | PostgreSQL | 사용자, 분석 기록 |

## 경쟁 우위 / 차별화 전략

1. **한국 법률 특화**: 한국 민법/상법/주택임대차보호법 기반 분석
2. **압도적 가격**: 변호사 상담 5~10만원 vs 건당 5,000원
3. **즉시 결과**: 변호사 예약/상담 대기 vs 업로드 즉시 분석 (3분 내)
4. **시각적 리포트**: 조항별 색상 표시로 비전문가도 한눈에 이해

## 리스크 및 고려사항

| 리스크 | 대응 방안 |
|--------|-----------|
| AI 분석 오류로 인한 법적 책임 | "참고용" 면책 고지 필수, 법적 자문 대체 불가 안내 |
| 변호사법 위반 가능성 | 법률 자문이 아닌 "정보 제공" 서비스로 포지셔닝, 법률 검토 |
| AI 할루시네이션 (없는 법률 인용) | RAG 기반 실제 법률 조문 참조, 출처 표시 |
| 초기 사용자 신뢰 확보 어려움 | 법률 전문가 자문단 구성, 정확도 수치 공개 |
